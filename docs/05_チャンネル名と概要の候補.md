# チャンネル名・概要文・タグの候補

参照チャンネル「考えすぎる葦」の実データ(`knowledge/reference-channel/channel-meta.md`)から抽出した法則に沿って作成。

---

## 先に、避けるべき衝突について

現行のシグネチャ「**そんなことを、また考えすぎてしまいました。**」は、**参照チャンネルの名前「考えすぎる葦」を回収する台詞そのもの**である。向こうは名前・締めの台詞・姿勢が1本の線でつながっており、この台詞は事実上あちらのブランド資産になっている。

台本の構成や切り口を寄せるのは戦略として成立するが、**締めの台詞まで同一だと、別チャンネルとして認識されにくくなる。** チャンネル名を決めるときに、締めの台詞も自分の名前を回収する形へ差し替えることを勧める。各候補にその案を併記した。

---

## チャンネル名の候補5案

命名の法則:①誰でも知っている成句を選ぶ ②**1語だけ**ずらす ③ずらした語がチャンネルの姿勢になる ④シグネチャで毎回回収する ⑤4〜8字で読みが一意。

### 案1 **万物の値札**(ばんぶつのねふだ) ← 推薦

- 元ネタ:プロタゴラス「人間は万物の尺度である」
- ずらし:尺度 → 値札
- 姿勢:**41ビート設計図のブロックD(帳簿)がこのチャンネルの背骨**であり、「誰がいくら儲け、原価は何か」を毎回必ず問う。その姿勢が名前になる
- シグネチャ案:「**そんなものにまで、また値札を見つけてしまいました。**」
- 強み:検索でほぼ競合しない。5字で短い。読みが一意
- 弱み:哲学の元ネタが「考える葦」ほど有名ではない

### 案2 **見えすぎる手**(みえすぎるて)

- 元ネタ:アダム・スミス「見えざる手」
- ずらし:見えざる → 見えすぎる
- 姿勢:市場が勝手に調整する、はずの構造を、可視化しすぎてしまう
- シグネチャ案:「**そんなところまで、また見えてしまいました。**」
- 強み:**「〜すぎる」という語形が参照チャンネルと同じ**なので、視聴者の語感がそのまま乗り換えられる。経済学タグとも噛む
- 弱み:語形が近すぎるとも言える。二番煎じに見えるリスク

### 案3 **オッカムの解剖刀**(オッカムのかいぼうとう)

- 元ネタ:オッカムの剃刀
- ずらし:剃刀 → 解剖刀
- 姿勢:「構造解剖」という看板を名前で直接名乗る
- シグネチャ案:「**そんなものまで、また解剖してしまいました。**」
- 強み:意味が一発で通る。硬派で信頼感がある
- 弱み:8字とやや長い。理系寄りに見えて俗な入口と落差が出にくい

### 案4 **俗物解剖学**(ぞくぶつかいぼうがく)

- 元ネタ:成句のずらしではなく、学問名の捏造(参照チャンネルの【自己家畜化】【超個体論】と同じ発想を名前に適用)
- 姿勢:俗×知の落差をそのまま名前にする
- シグネチャ案:「**そんなことを、また解剖しすぎてしまいました。**」
- 強み:何のチャンネルか一撃で分かる。タイトルの【学問×学問】タグと語感が揃う
- 弱み:「俗物」が視聴者への当てこすりに読まれうる。鏡のオチとは整合するが、初見では冷たい

### 案5 **知らなくていい図鑑**(しらなくていいずかん)

- 元ネタ:参照チャンネルの概要文「知らなくていいことほど気になってしまう人向け」を名前に昇格させたもの
- 姿勢:実利のない知識を集める場所であることを宣言する
- シグネチャ案:「**そんなことを、また知ってしまいました。**」
- 強み:平易で、視聴者が自分を名乗りやすい。共有もされやすい
- 弱み:格が下がる。学術データの重みと釣り合わない

**推薦は案1「万物の値札」。** 理由は、帳簿ブロックがこのシステムの必須ビートであり、他の教養系チャンネルが最も持っていない要素だからである。名前がそのまま差別化になる。語感の連続性を優先するなら案2。

## 概要文の候補3案

構造は参照チャンネルと同じ4ブロック。**③の訂正ポリシーは必ず入れる。** 学術データを扱う以上、間違いを認める姿勢の表明が信頼の担保になり、同時にコメント欄を罵倒ではなく検証へ誘導する。

### 案A 帳簿を前面に(案1の名前と組む)

```
世の中で当たり前になっている値段を、学術研究と公的統計で解剖する動画を投稿しています。
誰が、いくら儲けていて、原価は何なのか。毎回そこまで踏み込みます。
知らないままで困らないことほど、気になってしまう人向け。

※内容に誤りがあった場合は、コメント欄でご指摘ください。
確認のうえ、概要欄または固定コメントにて訂正します。

■ お仕事のご相談・お問い合わせ
(メールアドレス)
```

### 案B 落差を前面に(案3・案4の名前と組む)

```
誰もが知っている俗な現象を、実在の学術研究と精密な統計で解剖する動画を投稿しています。
神経科学、行動経済学、進化生物学、制度史。使えるものは何でも使います。
下世話な入り口から入って、賢くなった顔で帰りたい人向け。

※内容に誤りがあった場合は、コメント欄でご指摘ください。
確認のうえ、概要欄または固定コメントにて訂正します。

■ お仕事のご相談・お問い合わせ
(メールアドレス)
```

### 案C 鏡を前面に(案5の名前と組む)

```
身の回りの現象を、学術研究と統計データで解剖する動画を投稿しています。
最後はたいてい、話がこちら側に返ってきます。
知らなくていいことほど、気になってしまう人向け。

※内容に誤りがあった場合は、コメント欄でご指摘ください。
確認のうえ、概要欄または固定コメントにて訂正します。

■ お仕事のご相談・お問い合わせ
(メールアドレス)
```

**共通の書き方**

- 1文目で「何を、何で」を言い切る。参照チャンネルと同じ
- 2文目で他との違いを1つだけ足す
- 3文目は**視聴者に自分だと名乗らせる一文**にする。「〜な人向け」の形を守る
- 煽らない。動画の文体と同じ静かな断定にする

## チャンネルタグの候補

参照チャンネルは18語。**学問名・ジャンル語・YouTube検索語・ニッチ語の4層で構成されている。** 同じ設計で20語を用意した。

### 推奨(20語)

```
科学 サイエンス 解説 雑学 教養 考察 統計学 経済学 心理学 社会学
行動経済学 進化心理学 制度史 データ分析 知的好奇心 大人の学び直し
なぜシリーズ 構造 帳簿 値段の話
```

### 内訳

| 層 | 語 | 狙い |
|---|---|---|
| ジャンル語 | 科学、サイエンス、解説、雑学、教養、考察 | 「科学」と「サイエンス」は参照チャンネル同様、表記ゆれを両方入れる |
| 学問名 | 統計学、経済学、心理学、社会学、行動経済学、進化心理学、制度史 | **タイトルの【学問×学問】タグと一致させる。** 使う学問が変わったら差し替える |
| 検索需要 | データ分析、知的好奇心、大人の学び直し | 教養系の既存需要に接続する |
| 独自 | なぜシリーズ、構造、帳簿、値段の話 | このチャンネル固有。「帳簿」と「値段の話」は他の教養系がほぼ使っていない |

### 採用しなかった語と理由

- **ゆっくり解説** — 参照チャンネルは入れているが、実際にはゆっくり解説ではない。検索の実利はあるが、ジャンル不一致のタグは推薦の精度を下げうる。**AI音声で語る中尺という形式が同じでないなら、外すことを勧める**
- **高学歴、恋愛工学** — 参照チャンネルの初期テーマ(恋愛・モテ)に対応した語。こちらのテーマ設計が学歴や恋愛に寄らないなら、視聴者層を誤らせる
- **検証してみた** — 実験系の期待を持たせる。本チャンネルは既存研究の解剖であって自前の検証ではないため、期待とずれる

## 決めた後にやること

1. チャンネル名を決めたら、**シグネチャを名前を回収する形に差し替える**。`tools/beats.json` の `signature` と `.claude/skills/daihon/references/beats.md` のビート41、`references/audit.md` を同時に更新する必要がある(機械監査がシグネチャ一致を見ているため)
2. ハンドル(@から始まる文字列)は名前のローマ字読みにする。参照チャンネルは `@kangaesugiruashi` で、名前をそのままヘボン式にしている
3. 概要文のメールアドレスは実在のものを入れる。空欄のままだと案件の取りこぼしになる
