# 自己改善レポート:テスト台本のA〜D比較評価と改善内容

## 評価方法

システム(02の指示書)でテスト台本「なぜ人は推しに、恋人より多くの金を払えるのか」を生成し、A〜Dの高再生台本と10項目で比較。不合格項目を修正し、修正から得た教訓をシステム側(プロンプト)にフィードバックした。

## 実施した改善(台本側)

1. **冒頭強化**:中国規制の「原因」である2021年5月の乳飲料大量廃棄事件(投票QRコード目当ての買い占め)を映像的情景として追加。抽象的な「規制」より視覚的で、怒り・驚きの感情の火種が強い
2. **帳簿の章を新設**:CD複数枚商法の原価構造、原価ゼロの「時間」という商品、ファンが自腹で払う広告費(生誕祭文化)。A〜Dの「どこ元の帳簿を開く」に相当する必須要素を補完。同時に「運営が悪いという単純な話ではない」の一文で悪玉化を回避
3. **情景の追加**:コンビニのオンラインくじ(第2幕)、卒業発表直後の深夜のSNS(第4幕)の2シーンを追加し、データ⇄情景の交互リズムを回復
4. **研究の追加**:損失回避(カーネマン&トヴェルスキー)、公認されない悲嘆(ドーカ)を追加。フルセット引用は計10本に
5. **結果**:4,982字 → 6,122字(推定19.1分)。A(約6,100字)と同水準に到達

## 実施した改善(システム=プロンプト側へのフィードバック)

テストで発覚した欠陥をルール化し、再発を防止:

1. **「金の流れ・帳簿」視点の義務化**:第3幕の指示に「台本のどこかに必ず1回、誰がいくら儲け原価は何かの視点を入れる」を明文化(初稿が落とした要素)
2. **文字数基準の較正**:目標を6,500〜8,000字から6,000〜8,000字へ修正(A〜Dの実測値6,100〜7,200字に整合)。セルフチェック項目に実測値を併記
3. **TTS記号ルールの修正**:中黒「・」の全面禁止が外国人名(ドナルド・ホートン等)と衝突することが判明。外国人名の区切りに限り許可へ修正

## 原典を超えたと判断できる点(差別化要素)

1. **メタCTA**:「この動画への親しみ自体がパラソーシャル関係であり、登録ボタンはその予約装置だ」と、CTAを動画テーマの実演に変換。原典のCTAは定型文の付け足しだが、本システムでは登録行為そのものがオチの一部になる(テーマと接続可能な場合のみ発動する任意ルールとしてシステムに実装済み)
2. **ファクトチェックリストの標準装備**:原典は研究引用の正確性を担保する仕組みを持たないが、本システムは全主張を出典・確度つきで列挙し、公開前検証を運用に組み込んだ。チャンネルの生命線である「信頼」をスケール時にも維持できる
3. **制作メモの同時出力**:タイトル案3・サムネ文言案3・概要欄を台本と同時に納品し、量産ワークフローの工数を削減
4. **裏切り予告・章末疑問文・情景挿入を「位置とノルマつきのルール」として形式化**:原典は作者の職人技だが、本システムは再現可能な仕様書になっており、テーマが変わっても品質が落ちない

## 残る運用上の注意

- 数値の最終責任は公開者にある。ファクトチェックリストの「要確認」項目(市場規模の最新値、スパチャランキング等)は公開前に必ず検証すること
- web検索が有効な環境で実行すると、執筆前の実在確認により精度がさらに上がる
- 同一構成の量産はチャンネル内での型疲れを起こしうる。10本に1本程度、冒頭パターン(数字始まり/情景始まり/事件始まり)をローテーションすることを推奨(STEP1の冒頭フック欄で選択可能)
