# チャンネルアイコン「余計な解剖学」の生成プロンプト

参照チャンネル「考えすぎる葦」のアイコン実物を解析して作成。

---

## 参照チャンネルのアイコン解析

**手描きの鉛筆と色鉛筆によるスケッチを、しわの寄った紙のままスキャンした画像。** 擬人化された葦が岩に腰かけ、ロダンの「考える人」の姿勢で頬杖をつき、困り顔をしている。緑と茶の2色だけ。文字は一切ない。

### 読み取れる設計

1. **チャンネル名の視覚的ダジャレになっている。** 「考えすぎる葦」→ 葦が考える人のポーズ。名前を知らなくても、絵を見れば名前が分かる
2. **あえて素人っぽい。** サムネイルは極めて作り込まれているのに、アイコンだけ手描きの落書き。この落差が「中の人」の存在感と親しみを作っている
3. **表情がある。** 困り顔、眉のハの字。ロゴではなくキャラクターとして扱われている
4. **色は2色まで。** 緑と茶。背景は紙の白
5. **文字なし**

### ただし、真似すべきでない点

**線が細く、描き込みが多いため、小さく表示されると潰れる。** YouTubeのアイコンは一覧やコメント欄で24〜48ピクセルで表示される。この解像度で判別できるのは「縦長の緑色の何か」までである。

したがって本チャンネルのアイコンでは、**手描きの質感と親しみは踏襲しつつ、シルエットを太く単純にする。**

---

## 共通の制約(3案すべてに入れる)

- **正方形。円形に切り取られる前提**で、主体を中央に置き、四隅に余白を取る
- **24ピクセルでも判別できる、太い線と単純なシルエット**
- **文字を入れない。** アイコンサイズでは日本語は絶対に読めないうえ、画像生成では崩れる
- **色は2色まで。** 背景は紙の白か、単色のベタ
- 出力は800ピクセル四方以上

---

## 案1 解剖された「はてなマーク」 ← 推薦

**狙い**:チャンネル名の視覚的ダジャレ。**疑問そのものを解剖している**という、コンセプトの一撃の説明になる。図形が単純なので24ピクセルでも崩れない。

```
正方形の画像を1枚作ってください。YouTubeのチャンネルアイコン用です。
円形に切り抜かれるので、主体は中央に置き、四隅は余白にしてください。
文字は一切入れないでください。

白い紙の上に、大きな「?」の記号が1つだけ、横たわって置かれています。
この「?」は生き物の標本のように扱われていて、
胴体にあたる曲線部分が縦にすっと切り開かれ、左右にわずかに開いています。
開いた断面の内側には、歯車、細い配線、小さな心臓のような形が、
簡素な線画で詰まっているのが見えます。
「?」の下の点の部分は、切り離されて少し離れた場所に転がっています。

「?」の周囲には、細いピンが4本、標本を留めるように斜めに刺さっています。
下には解剖台を思わせる浅いトレイの輪郭を、細い線で1つだけ描いてください。

画風は、鉛筆と色鉛筆による手描きのスケッチ。
線は太く、はっきりと。細かい描き込みは避けてください。
紙はわずかにしわが寄り、質感が残っている状態にしてください。

色は2色のみ。「?」の輪郭と内部は濃い墨色、
切り開かれた断面の内側だけをくすんだ赤で塗ってください。
背景は紙の白のままにしてください。
```

**強み**:意味が一発で通る。図形が単純で最小サイズでも読める。テーマを限定しない
**弱み**:キャラクターではないので、参照チャンネルほどの親しみは出にくい

## 案2 白衣を着た人物が、どうでもいい物を解剖している

**狙い**:参照チャンネルと同じ「手描きキャラクター」路線。**「余計」を、解剖する対象の下らなさで表現する。** 親しみが最も出る。

```
正方形の画像を1枚作ってください。YouTubeのチャンネルアイコン用です。
円形に切り抜かれるので、主体は中央に置き、四隅は余白にしてください。
文字は一切入れないでください。

白い紙の上に、白衣を着た人物が1人だけ、上半身だけ描かれています。
その人物は椅子に座り、机の上のものを前かがみで覗き込んでいます。
片手に細いメスを持ち、もう片方の手にルーペを持っています。
表情は真剣そのもので、眉間にしわが寄っています。
顔は簡素で、目は点、口は真一文字にしてください。

机の上に置かれ、いま解剖されているのは、
中身を取り出されて開かれた、ごく普通のカップ麺の容器です。
麺やスープではなく、細い線で描かれた歯車と配線が中から出ています。

画風は、鉛筆と色鉛筆による手描きのスケッチ。
線は太く、はっきりと。細かい描き込みは避けてください。
紙はわずかにしわが寄り、質感が残っている状態にしてください。

色は2色のみ。人物と机は濃い墨色の線だけで描き、
カップ麺の容器だけをくすんだ赤で塗ってください。
背景は紙の白のままにしてください。
```

**強み**:キャラクターとして育てられる。「余計」の意味が笑いとして伝わる
**弱み**:人物と小物で要素が2つあるため、24ピクセルでは何を解剖しているか分からなくなる

## 案3 交差したメスと、その下のはてなマーク

**狙い**:学会のエンブレム風。**3案中いちばん小サイズでの視認性が高い。** 硬派に振る場合の選択肢。

```
正方形の画像を1枚作ってください。YouTubeのチャンネルアイコン用です。
円形に切り抜かれるので、主体は中央に置き、四隅は余白にしてください。
文字は一切入れないでください。

濃い紺色のベタ塗りを背景にしてください。
その中央に、2本の解剖用メスを、刃を上に向けてバツの字に交差させて配置します。
メスは太い輪郭で、単純化されたシルエットとして描いてください。

交差した2本のメスのちょうど下に、大きな「?」の記号を1つだけ、
メスと同じ太さの輪郭で置いてください。
「?」の下の点は、通常より少し大きくしてください。

全体を、細い円形の枠が1本だけ囲んでいます。
枠の内側には模様や装飾を入れないでください。

画風は、フラットなベクターイラストのエンブレム。
陰影、グラデーション、質感は一切入れないでください。
線と面だけで構成してください。

色は2色のみ。メスと「?」と円枠は生成りの白、背景は濃い紺色。
```

**強み**:最小サイズでも確実に判別できる。バナーやグッズに展開しやすい
**弱み**:硬い。参照チャンネルのような「中の人」の親しみが出ない

---

## 選び方

**推薦は案1。** コンセプト(疑問を解剖する)を図形1つで説明でき、視認性も確保でき、テーマを限定しない。参照チャンネルの手描き路線も踏襲している。

親しみとキャラクター展開を優先するなら案2、視認性と硬派さを優先するなら案3。

## 生成後に確認すること

1. **24ピクセルに縮小して見る。** 何であるか判別できなければ、線を太くして描き込みを減らす指示を足して引き直す
2. **円形に切り抜いて見る。** 四隅を切られても主体が欠けないか
3. 意図しない文字や記号が紛れ込んでいないか。画像生成は指示していなくても文字を描くことがある
