# 市場リサーチ:同ジャンル横断の実測(2026年8月)

参照チャンネル1本だけを見ていた従来の分析を、**同ジャンル47チャンネル・705本**へ広げて取り直した。

## 方法と、その限界

1. YouTube検索を再生数順で16クエリ実行し、動画256本を収集
2. そこに登場したチャンネルのIDを抽出し、RSSから直近15本の再生数を取得
3. **各動画を「自チャンネルの中央値の何倍か」に正規化**(47チャンネル・705本)

**重要な注意。** 素の再生数どうしを比べる分析は、**こちらが選んだ検索語に汚染される。** 実際、最初に「なぜ」を含むクエリを多用したまま特徴量を比較したところ「なぜ〜のか型は再生が低い」という結論が出たが、これは「なぜ」で検索したから小規模チャンネルが大量に混ざっただけの見せかけだった。**チャンネル規模を固定できる同一Ch内比だけが信頼できる。** 以下はすべて同一Ch内比である。

---

## 発見1 タイトルの型の効果は、小さい

同一Ch内の中央値を1.00としたときの倍率。

| 特徴 | 本数 | 倍率 |
|---|---|---|
| **否定・不能形**(できない、してはいけない、なかった) | 54 | **1.19** |
| **自己ラベリング**(あなた、〜な人の特徴、タイプ) | 56 | **1.15** |
| **恋愛・モテ・性** | 57 | **1.11** |
| なぜ〜のか | 131 | 1.00 |
| 本当は・真実・正体 | 72 | 1.00 |
| 数字を含む | 194 | 1.00 |
| 脳・心理 | 135 | 1.00 |
| 金・仕事 | 60 | 0.95 |
| 歴史・国・地理 | 66 | 0.93 |

**「なぜ〜のか」に効果はない。** このジャンルでは全員が使っているので、差がつかない。参加費であって、武器ではない。

効いているのは**否定・不能形**と**自己ラベリング**だが、いずれも1.1倍から1.2倍にとどまる。**タイトルの型では、せいぜい2割しか動かない。**

## 発見2 桁で効いているのは、テーマである

自Ch中央値の10倍以上に伸びた本を並べると、型ではなくテーマが見える。

```
x144  知らないと損する睡眠の雑学                      283万
x58   前世がすべて分かる診断テスト                    114万
x52   これを感じたら付き合うのは絶対にやめてください        270万
x28   最も革命的な器官ー陰茎の進化                     70万
x20   タカとワシとトビの違い                          25万
x18   恋愛でいつも失敗する人がみんなやっていること          94万
x14   ダーウィンのパラドックスー同性愛行動の進化           35万
x13   知らないと損する健康の雑学                       26万
x13   みんな結局どんな顔が好きなのか                    10万
x12   人を見る目がある人の対処                         5万
x12   MBTI診断 INTPの性格と恋愛傾向                   4万
x11   最も謎な器官ー陰嚢の進化                        28万
```

クラスターは4つ。

1. **睡眠と健康の実用**(最大の外れ値)
2. **恋愛の危険信号・見抜き方**
3. **身体と性の進化**(同一Chで x28・x14・x11 と連発しており、偶然ではない)
4. **自己診断・自己ラベリング**(MBTI、前世診断、〜な人の特徴)

**タイトルの型が1.2倍なのに対し、テーマは10倍から100倍動く。** 力の入れどころはテーマ選定であって、タイトルの語尾ではない。

## 発見3 尺は15分から20分に集まる

同一Ch内比では尺の効果は明確に出なかったが、**このジャンルの実務的な標準は15分から20分**である。本システムの23分前後はやや長い。

## 発見4 参照チャンネルの順位は動く

7月時点の実測と8月の再取得で、順位が入れ替わっていた。

| タイトル | 7月 | 8月 |
|---|---|---|
| なぜ面白い人は、イケメンでなくてもモテるのか | 149,196 | **170,102** |
| なぜ識字率が上がると国が滅びるのか | 24,363(下位) | **47,733**(上位) |

**公開直後の数字で「伸びた・伸びない」を判定してはならない。** 少なくとも数週間は動く。

## 本システムへの反映

| 発見 | 反映 |
|---|---|
| タイトルの型は1.2倍まで | 型の議論に時間を使いすぎない。**ただし否定・不能形は引き続き優先**(実測1.19倍で最良) |
| テーマが10倍から100倍 | **STEP1の重心をテーマ選定に置く**。既存の「当事者性が筆頭」は正しかった |
| 睡眠・健康が最大クラスター | 未使用。ただし「なぜ睡眠は淘汰されなかったのか」は飽和(151万・114万・21万と量産済み)。**角度を変えて入る** |
| 身体と性の進化が反復して当たる | 未使用。将来の候補 |
| 自己ラベリングが1.15倍 | 二人称の密度規律と整合。すでに実装済み |
| 尺15分から20分 | 現行は23分前後。**6,300字前後まで詰める余地がある** |

## 飽和の確認は毎回やること

テーマを決めたら、**そのテーマの検索結果を再生数順で引き、既に誰が何本出しているかを見る。** 需要が大きいクラスターほど飽和もしている。狙うのは「需要は大きいが、その角度だけ空いている」場所である。
