## サムネ文言の4つの型

### 型1 「◯◯のパラドックス」型(4枚)

搾取のパラドックス / 港区女子のパラドックス2 / 客寄せパンダのパラドックス / 聖地巡礼のパラドックス

**シリーズ化されたブランド語。** 上段に対象を赤、下段に「パラドックス」を白か紺で置く。文言を考える手間がゼロになるうえ、チャンネルの記号として蓄積する。**最も安全で、最も再利用が効く型。**

### 型2 造語・比喩の名詞型(5枚)

終生浮遊人 / 成熟という名の去勢 / 月曜日の蟻 / リビングデッド企業の呼び声 / 武器の収斂進化

**台本の結論を、詩的な名詞句に圧縮する。** 意味が半分しか分からないので、確かめたくてクリックが起きる。5〜13字。文学寄りで格が上がるが、外すと何の動画か分からなくなる。

### 型3 疑問文型(5枚)

ユーモアは何と相関するか? / なぜ捕まらない? / 日本で一番多い店は? / 異世界転生はなぜ流行るのか? / 脳の大きさ ≠ 知性?

**最高再生の149,196回はこの型。** クイズとして機能し、答えを知りたくさせる。**タイトルの疑問文をそのまま短縮するのではなく、もっと素朴で子供っぽい問いに落とすのがコツ**(「なぜ国家は違法を見て見ぬふりするのか」→「なぜ捕まらない?」)。

### 型4 映画・作品パロディ型(2枚)

その男、色欲につき(『その男、凶暴につき』) / リビングデッド企業の呼び声(遊戯王のカード名)

既存作品の題を1語だけ差し替える。**絵柄もパロディ元に寄せる**(前者は昭和のヤクザ映画ポスター、後者はトレーディングカードの実物模写)。当たると強いが、元ネタを知らない層には効かない。

## 配色の法則(全15枚が守っている)

1. **文字は必ず2色で組む。** 1色だけの例は1枚もない
2. **赤(または朱・臙脂)が必ず入る。** 15枚中14枚。残る1枚もピンク
3. **もう1色は、白・紺・金・水色のどれか**
4. **背景は白系(6枚)か暗黒系(9枚)の二択。** 中間の灰色やパステルの背景は1枚もない
5. 文字には必ず縁取りかテクスチャが乗る。ひび割れ、かすれ、紙の粒子、袋文字

## 配置の法則

- **文字は左寄せが12枚/15枚。被写体は右。** 中央配置は2枚、全面は1枚
- 文字は画面の**左半分の縦方向いっぱい**を使う。上下2行、それぞれ5〜7字
- 被写体が人物のときは**顔を右端に大きく**。目線はカメラか、上を見上げる
- 記号(≠、?)を使うときは、文字と同じか倍の大きさにする

## 文字はAIに描かせているのか

**ほぼ確実に、後から乗せている。** 根拠は以下。

- 書体が完全に均一で、1文字も崩れていない。画像生成の日本語出力ではまず起きない
- 袋文字、グラデーション、ひび割れテクスチャが文字の輪郭に正確に沿っている
- 「パラドックス」の4枚で、同じ書体と同じ縁取りが再利用されている
- 絵の情報量が多い画面でも、文字の乗る領域だけ情報が落ちている(背景を後からぼかすか暗くしている)

つまり参照チャンネル自身は、**絵を生成 → 文字を乗せる**という2工程で作っている。

**ただし、本システムのプロンプトは文字も含めて指定する。** 文字を指定しないプロンプトは、この型のサムネの設計図として不完全だからである。文字の位置、行組み、色分け、書体を書いて初めて、絵の側に必要な余白と暗さが決まる。

生成結果の日本語が崩れた場合の対処は2つ。ひとつは同じプロンプトで数回引き直すこと。もうひとつは、そのプロンプトの末尾を「文字は入れず、指定した位置を余白のままにしてください」に差し替えて絵だけを取り、文字を後から乗せることである。**どちらの場合も、文字の指定そのものは最初から書いてある必要がある。**

### ここから読み取れる、文字指定の必須項目

1. **強調する1語を必ず決める。** 15枚すべてで、文言のうち1語だけが赤(または朱・紅・ピンク・金)で、残りは白か黒か紺。**赤くする語は、台本の核心にあたる名詞か動詞**
2. **助詞は小さく、別の色にする。**「の」「は」を主要語と同じ大きさ同じ色で並べた例は1枚もない
3. **行は2〜4段。** 1行にすべてを流した例は13番のみ
4. **文字の縁取りかテクスチャを必ず指定する。** ひび割れ、かすれ、黒縁、墨だまり、押し出しの立体
5. **書体は明朝系か毛筆系がやや多い**(明朝5・毛筆3・ゴシック7)。テーマが重いほど毛筆や明朝に寄る
