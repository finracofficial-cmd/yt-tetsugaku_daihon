
## ① 導入エッセイ

**本編の要約ではない。読み物として別に書き下ろされている。** 実物はどれも800〜1200字あり、概要欄というより短いコラムである。

> **本チャンネルではここを300〜450字に短縮する。** これは参照Chの実測から意図的に外す判断であり、誤りの修正ではない。参照Chの長さは概要欄というより記事だが、スマートフォンでは「もっと見る」を押さないと3行しか見えないため、**先頭の数行で問いまで到達させる**ことを優先する。構成は同じで、量だけを絞る。

構成は本編のブロックAを引き伸ばしたもの。

1. **具体から入る。** ことわざ、情景、風習など。冒頭に「──」を置く例もある
2. **その具体を、本編のテーマの構造に接続する**
3. **数字か事実を1つ置く**
4. **中心の問いで段落を終える。答えは書かない**
5. 場合により、飛び道具の素材(生き物、歴史)をここで先出しして興味を引く

実例(識字率の回):「風が吹けば桶屋が儲かる」の因果連鎖を説明 → 同じ形をした「誰も笑えない連鎖」がある → 国が文字を配ると国家が倒れるという連鎖を提示 → 2024年の先進国の選挙で与党が軒並み票を減らした事実 → 「ではなぜ国家は自らを滅ぼしかねない読み書きを配り続けるのか」

## ② 締めの1文

**必ずこの形で終える。**

> 今回は「(タイトルの問い)」を、(学問A)と(学問B)の観点から**考えすぎてみました。**

**チャンネル名を回収するシグネチャが、本編の末尾だけでなく概要欄にもある。** 本チャンネルなら「解剖してみました」に置き換わる。

## ③ 関連動画(任意)

姉妹編があるときだけ。一言の紹介とURL。

## ④ タイムスタンプ

**Prologue、Chapter 1〜4、Epilogue の6ブロック。** 各ブロックに詩的な章題がつく。

```
00:00 - Prologue:風が吹けば、王が倒れる
02:51 - Chapter 1:アルファベットを縛る法律
06:22 - Chapter 2:北極の熊は何色か
11:40 - Chapter 3:自ら配った「もしも」という導火線
15:30 - Chapter 4:溺れさせる
21:50 - Epilogue:虚の玉座で、迷う言葉
```

章題は内容の説明ではなく、**短い詩句**である。「溺れさせる」のように動詞1語のこともある。

## ⑤ 参考文献・データ出典

**1件ごとに空行で区切り、通し番号を角括弧で振る。8件以上。**

```
[3] Dehaene, S. et al. (2010). "How Learning to Read Changes the Cortical
Networks for Vision and Language." Science.（読み書きの習得が視覚・言語に
かかわる脳のネットワークを実際に組み替えることを示した）
```

書式の要点。

- **英語文献は英語のまま。** 著者、発表年、論文題、掲載誌の順。PMIDまで書いている例もある
- **日本語の資料は日本語のまま。** 官公庁の統計、判例、国内調査
- **丸括弧の中に、日本語で必ず補足を書く。** 何を示した研究か、被験者数、結果の数値、注意すべき限界
- **書籍、判例、法律、統計、古典的観察も同じ番号体系に混ぜる。** 学術論文だけに限らない
- 番号は本文中に対応させるのではなく、**登場順に振るだけ**

## 本システムとの対応

| 参照Chの要素 | 本システムでの作り方 |
|---|---|
| 導入エッセイ | ブロックA(ビート1〜6)を土台に、**別に書き下ろす。** 本文の引き写しにしない |
| 締めの1文 | 「今回は「〜」を、◯◯と◯◯から**解剖してみました。**」 |
| タイムスタンプ | 41ビートを6ブロックに束ねる。Prologue=A、Chapter1=B、Chapter2=C、Chapter3=D、Chapter4=E+F、Epilogue=G。時刻は `tools/timestamps.py` が字数から算出する |
| 参考文献 | **工程1の素材台帳がそのまま材料になる。** 台帳の各行に番号を振り、丸括弧の補足を足す |

**素材台帳を15行以上作らせている理由が、ここでも効く。** 台帳がそのまま出典リストになる。
