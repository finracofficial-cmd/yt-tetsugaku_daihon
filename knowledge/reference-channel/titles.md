# タイトルとテーマの実測 — 参照チャンネル全93本

**この文書は v3.2 までの15本版を置き換える。** 15本で出した結論のうち**2つは、93本では逆を向いていた。**

再現コマンド。

## 0. 前置き — 何が効いて、何が効かないか

93本の再生数は **12,000〜439,000、中央値51,000**。この散らばりを何が作っているか。

| 要因 | 効果 | 検定 |
|---|---|---|
| **テーマの区分** | **2.3倍** | 並べ替え検定 p=0.034 |
| **学問タグの選択** | **2.0倍**(進化心理学 対 進化生物学) | p=0.016 |
| タイトルの字数 | rho=+0.21 | p=0.049 |
| 読点の有無 | 1.21倍 | p=0.157 |
| タグの個数 | 1.3倍(2個が上) | p=0.137 |
| 疑問符の有無 | 0.84倍(付けない方が上) | p=0.294 |
| 引用符の有無 | 1.08倍 | p=0.681 |
| 動画の尺 | rho=+0.08 | p=0.472 |
| **本文の構造(18指標)** | **すべてノイズ** | 補正後に有意なもの無し |

**桁が違う。** テーマと学問タグは2倍前後動かすが、タイトルの細部は1〜1.2倍、本文の構造にいたっては測定できるほどの差が無い。

**時間の使い方をここに合わせる。** テーマ選定に一番時間をかけ、タイトルはその次、本文は「型どおりに書く」だけでよい。

> **交絡について正直に書く。** 再生数は投稿からの経過時間に影響される(新しさ順位との相関 rho=+0.237、つまり古い動画ほど再生が多い)。以下の数字はすべてこの交絡を含む。統制した偏相関も併記できるものは併記した。

## 1. テーマの区分別(排他割り当て、93本)

| 区分 | 本数 | 中央値 | 平均 | その区分の最高 |

| **金と地位** | 5 | **65,000** | 151,200 | なぜ港区女子はみんな同じ見た目なのか |

**上位3区分(恋愛と性・社会と制度・金と地位、19本)の中央値96,000に対し、下位2区分(モノと現象・心と脳、14本)は42,000。2.29倍、p=0.034。**

### 何がこの差を作っているか

上位に共通するのは**当事者性**である。視聴者が「これは自分の話だ」と思える度合い。

- **恋愛と性** — 当事者はほぼ全員。しかも人に相談しにくいので、動画で答えを探す
- **金と地位** — 自分の位置を確認したい欲求。港区女子・夜職のような**外側から眺められる集団**を扱うと、当事者でない人も見る
- **社会と制度** — 「東京に出た若者」のように、**自分の人生の選択が主語**になっているものだけが伸びている。抽象的な制度論は入っていない

下位に共通するのは**「知って終わり」**であること。音楽で鳥肌が立つ理由を知っても、明日の自分は何も変わらない。

### 上位1/4と下位1/4のタイトルの語彙

| | 語 |
|---|---|
| 上位にだけ出る | モテ / 不幸 / 文献 / 不都合 / 事実 / 保存 |
| 下位にだけ出る | 本当 / 人類 / 武器 |

「本当なのか」型の検証、「人類」という主語の大きさ、これはどちらも当事者性を薄める。

## 2. 学問タグ

### 2-1 タグの個数 — v3.2の結論は逆だった

| タグ数 | 本数 | 中央値 | 平均 |
|---|---|---|---|
| 1個 | 43 | 48,000 | 61,558 |
| **2個** | **48** | **61,500** | **95,521** |

相関 rho=+0.156(p=0.137)、新しさを統制すると +0.269。

> **v3.2では「単独タグ6本の平均64,889に対し2個タグ9本は32,839で、ほぼ2倍の開き。学問タグは原則1個」と書いていた。これは n=15 の結論で、93本では逆である。** 2個の方がやや高い。有意ではないので「2個にすべき」とまでは言えないが、**「1個に絞れ」という規律は取り下げる。**

**現在の方針。1個でも2個でもよい。2個にするなら、2つ目は飛び道具の予告になっていること。**

### 2-2 どのタグか(3本以上)

| タグ | 本数 | 中央値 |
|---|---|---|
| **行動経済学** | 5 | **204,000** |
| **進化心理学** | 26 | **80,000** |
| 脳科学 | 14 | 61,500 |
| 経済学 | 3 | 57,000 |
| 情報経済学 | 3 | 54,000 |
| 社会心理学 | 9 | 51,000 |
| 神経科学 | 3 | 45,000 |
| データストーリーテリング | 3 | 39,000 |

**進化心理学(27本、中央値76,000)と進化生物学(16本、38,500)の差は1.97倍、p=0.016。**

名前は似ているが、扱うものが違う。**進化心理学は「人間のいまの行動」を説明し、進化生物学は「生き物の仕組み」を説明する。** 前者は当事者性があり、後者は無い。

**行動経済学の204,000は5本しかないので過信しない。** ただし港区女子・夜職・婚活市場のような**金と選択が絡む回**に付いており、区分1の結果と方向が一致している。

## 3. タイトルの書式

### 3-1 型 — 選択の余地はほぼ無い

| 型 | 本数 | 中央値 |
|---|---|---|
| 逆説なぜ型(「なぜ〜のか」) | **83** | 50,000 |
| その他の問い | 4 | 65,000 |
| 非問い(「〇〇が暴いた、〜の不都合な事実」等) | 5 | 91,000 |
| 常識検証型(「〜は本当なのか」) | 1 | 20,000 |

**93本中83本が逆説なぜ型。** これは型の選択ではなく、チャンネルの標準形である。

> v3.2では「逆説なぜ型12本の平均51,955に対し検証型・断罪型3本は20,478で3本とも下位」と書いた。93本でも検証型は1本だけで20,000と低いが、**n=1なので根拠にならない。**

非問い型5本の中央値91,000は目を引くが、これも n=5 である。ただし**「20の文献が暴いた、婚活市場の不都合な事実」(207,000)のような「文献数+暴いた+不都合な事実」構文は、上位にだけ出る語彙と一致している。** 第2案として試す価値はある。

### 3-2 字数 — v3.2の上限は短すぎた

| | p10 | 中央値 | p90 | 最大 |
|---|---|---|---|---|
| タグを含む総字数 | 25 | **31** | 40 | 46 |
| タグを除く字数 | 17 | **22** | 29 | 40 |

相関は総字数 rho=+0.207(p=0.049)、タグ除き rho=+0.221(p=0.034)。**長い方がわずかに高い。** ただし検定数で補正すれば残らない。

> **v3.2の「タグを含めて20〜29字。30字を超えたら作り直す」は、実物の中央値31字を下回っていた。** 上限を切る根拠が無いどころか、方向が逆である。

**現在の方針。タグを含めて25〜40字。** 46字が実測の最大なので、そこは超えない。

### 3-3 記号

| | 本数 | 中央値 | 判定 |
|---|---|---|---|
| 読点「、」あり | 47 | 57,000 | 1.21倍 / p=0.157 |
| 読点なし | 46 | 47,000 | |
| 疑問符「？」あり | 23 | 46,000 | 0.84倍 / p=0.294 |
| 疑問符なし | 70 | 54,500 | |
| 引用符「」“” あり | 47 | 54,000 | 1.08倍 / p=0.681 |
| 引用符なし | 46 | 50,000 | |

**3つとも有意ではない。** 検定の取り方で数字が動くことも明記しておく。二値を順位相関で見ると読点 p=0.046・疑問符 p=0.061 だが、中央値差の並べ替え検定では p=0.157・p=0.294 になる。**弱い検定のほうを採り、規律ではなく好みとして扱う。**

- 読点は打つ。「なぜ人は、歳を取るほど」の溜めは文体として有効で、実測も不利ではない
- 疑問符は付けない。「〜のか」で止める。新しさを統制した偏相関は -0.303 で方向は一貫している
- 引用符はどちらでもよい

### 3-4 述語

否定の失敗形を優先する。上位のタイトルに実在する形。

> 不幸にする / 消える / 気づけない / 終結しない / 冷める / 選ぶ / 捨て

「できない・なりきれない・気づけない・消せなかった」の系統である。

### 3-5 動画の尺

中央値19分(1,162秒)、範囲9〜29分。**再生数との相関は rho=+0.076(p=0.475)で無い。** 尺で勝負しない。

## 4. 次のテーマを選ぶときの手順

1. **区分から入る。** 恋愛と性 / 社会と制度(自分の人生の選択が主語) / 金と地位。この3つが2.3倍のところにある
2. **当事者性を一言で言えるか確認する。**「視聴者の何割が当事者か」。言えないテーマは、どれだけ面白くても下位に落ちる
3. **「知って終わり」になっていないか確認する。** 見た翌日の自分が何も変わらないテーマは、モノと現象の区分(41,000)に落ちる
4. **学問タグを決める。** 人間のいまの行動を説明できるタグを選ぶ(進化心理学・行動経済学・脳科学)。生き物の仕組みを説明するタグ(進化生物学)は1.97倍不利
5. **タイトルを書く。** なぜ〜のか / タグ込み25〜40字 / 読点あり / 疑問符なし / 述語は否定の失敗形

**素材が8本以上挙がらないテーマは、その場で捨てて別の案に差し替える。** これは実測ではなく制作上の規律である。

## 5. この分析の限界

- **n=93、区分ごとは4〜12本。** 区分別の中央値は、1本の大当たりで動く幅にある
- **交絡が統制しきれていない。** 経過時間・サムネ・投稿時期・アルゴリズムの変動
- **テーマ区分はキーワードによる機械割り当てである。**「その他・混合」が35本(38パーセント)あり、この分類は粗い
- **多重比較。** 個別の検定はいずれも p<0.05 前後で、検定数で補正すれば残らない。**「テーマが効き、構造は効かない」という大きな方向だけを信じ、個々の数字を精密なものとして扱わない**
