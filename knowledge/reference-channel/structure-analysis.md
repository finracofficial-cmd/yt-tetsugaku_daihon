# 参照チャンネル 全15本の構造解析と、再生を分けている要因

データ:チャンネルRSSから取得した直近15本の、タイトル・再生回数・概要欄(章タイムスタンプと出典リストを含む)。
取得日:2026年7月27日。再生回数は取得時点。

**注意:新規の文字起こしは取得できなかった。** YouTubeの内部APIは全クライアントでbot判定、ヘッドレスブラウザは環境のプロキシが外部通信を通さず、外部の文字起こしミラーはCloudflareで遮断された。したがって本文レベルの解析は、手元にある台本A〜D(4本)の範囲にとどまる。**以下の解析は、15本の章構成・尺・出典数・タイトルという「外形」の実測に基づく。**

---

## 発見1 6章構成は例外なく守られている

**15本すべてが Prologue / Chapter 1 / Chapter 2 / Chapter 3 / Chapter 4 / Epilogue の6章。** 5章も7章も1本もない。

### ブロック別の長さ(実測、分)

| ブロック | 中央値 | 幅 |
|---|---|---|
| Prologue | 2.5 | 2.0 〜 3.1 |
| Chapter 1 | 4.2 | 2.8 〜 5.6 |
| Chapter 2 | 4.2 | 3.1 〜 6.0 |
| Chapter 3 | 4.1 | 2.9 〜 5.7 |
| Chapter 4 | 3.6 | 2.7 〜 6.3 |
| Epilogue 開始 | 18.0 | 16.6 〜 22.3 |

**Prologueが3分を超えた例は1本もない。** 本編4章はどれも4分前後で、Chapter 4だけがやや短い。

## 発見2 尺・Prologueの長さ・出典数は、再生と関係していない

| | 上位5本 | 下位5本 |
|---|---|---|
| Prologue平均 | 2.39分 | 2.38分 |
| 尺(Epilogue開始) | 18.6分 | 18.8分 |
| 出典数の平均 | **9.2件** | **13.8件** |

**出典は多いほうが伸びていない。むしろ逆である。** 出典数は6〜19件と幅があるが、上位5本の平均は9.2件、下位5本は13.8件。最多の19件は24,363回、最少の6件は85,012回だった。

因果は断定できない(ニッチなテーマほど資料を要する、という交絡がありうる)。**だが「出典を増やせば厚みが出て伸びる」という仮説は、この標本では支持されない。**

## 発見3 学問タグは、1個のほうが2個より強い

| タグ数 | 本数 | 平均再生 | 中央値 |
|---|---|---|---|
| **1個** | 6本 | **64,889** | 42,928 |
| 2個 | 9本 | 32,839 | 24,677 |

**単独タグの平均は、2個タグのほぼ2倍。**

単独タグの回:【進化心理学】153,711 /【社会心理学】86,685 /【超個体論】45,856 /【自己家畜化】40,001 /【進化生物学】35,681 /【進化心理学】27,405

ここにも交絡はある。単独タグの回はテーマが人間の普遍的行動(モテ、性格、労働)で、2個タグの回はニッチ寄り(武器の形、識字率、聖地巡礼)だった。**それでも「学問を2つ並べるほど権威が増して伸びる」は否定される。**

## 発見4 タイトルの型は、逆説なぜ型が圧倒的

| 型 | 本数 | 平均再生 |
|---|---|---|
| **逆説なぜ型**(なぜ〇〇は、△△なのか) | 12本 | **51,955** |
| 検証・断罪型(「〜」は本当なのか/〜は愚かなのか) | 3本 | 20,478 |

**検証・断罪型の3本は、15本中の下位に固まっている**(26,932 / 18,023 / 16,480)。

これは本システムの従来指示「3つの型で1案ずつ作る」を修正すべき点である。**型の多様性は案出しの幅としては有用だが、本命は必ず逆説なぜ型にする。** 検証型と断罪型は、俗説そのものが強力に流通している場合の予備手段にとどめる。

## 発見5 伸びているのは「自分の損得に直結するテーマ」

上位5本:モテと容姿 / 奪われることと満足 / 国家と違法 / 港区女子と結婚 / 働きアリと労働
下位5本:聖地巡礼 / 脳の大きさ / 識字率と国家 / 都会の孤独 / 武器の形

**上位は人間関係と自分の損得。下位はモノ、歴史、特定集団。**

決定的なのは**視聴者の当事者性**である。武器の形もパンダも識字率も、面白いが「自分の話」にならない。都会の孤独は内面の話だが対象が限定される。

**テーマ選定でまず問うべきは「視聴者の何割が当事者か」。** 学問の面白さや素材の量ではない。

## 発見6 章題は説明ではなく詩句である

実例(上位3本)。

```
[153,711] Prologue 目減りする値打ち / Ch1 自己申告の罠 / Ch2 針の穴を撃ち抜く言葉
          Ch3 付け焼き刃の有効期限 / Ch4 久遠の、薪をくべる者 / Epi 気高き喜劇役者
[ 86,685] Prologue 満ち足りた被害者 / Ch1 私が選んだ、という物語 / Ch2 自由という終身刑
          Ch3 神殿の跡地に生まれた商売 / Ch4 自己消去という商品 / Epi 正気の計算
[ 85,012] Prologue 世界一奇妙な、数メートル / Ch1 合法が描かれた地図 / Ch2 禁じられた洪水
          Ch3 世界の地下水路 / Ch4 いちばん低い土地に沈む者 / Epi 薄目の作法
```

規則性。

- **ほぼすべてが名詞句。** 動詞で終わる例は少数
- **矛盾語を隣接させる**(満ち足りた被害者、自由という終身刑、物差しという凶器、気高き喜劇役者)
- **内容を説明しない。** 「自己申告の罠」からは中身が分からない。分からないから次章まで見る
- 6〜12字程度

## 本システムへの反映(v3.2で対応済み)

| 発見 | 旧仕様 | 反映 |
|---|---|---|
| 6章構成が絶対 | ─ | 41ビートを6ブロックに束ねる対応表を `tools/timestamps.py` に実装 |
| Prologueは3分以内 | ブロックA=580字(1.8分) | **ブロックAを820字(2.5分)に拡張。** 実測中央値に合わせ、増分をビート5「意外な予告リスト」に充てた |
| 出典は多いほど良くない | 素材台帳15行以上 | **台帳15行は維持**(執筆の材料として必要)。**概要欄に載せる出典は8〜10件に絞る。** 台帳と出典リストを1対1にしない |
| 学問タグは1個が強い | 「1個でも成立する」 | **「原則1個。2個にするのは、2つ目がビート17の飛び道具の予告になる場合のみ」** に強化(SKILL.md) |
| 逆説なぜ型が2.5倍 | 「3つの型で1案ずつ」 | **本命は必ず逆説なぜ型、第1案に置く。検証型・断罪型は予備**(SKILL.md のタイトル型の表に位置づけ列を追加) |
| 当事者性が最大の要因 | 選定基準の中の1項目 | **選定基準の第1位に格上げ。** STEP1の各案に「視聴者の何割が当事者か」の項目を新設 |
| 章題は詩句 | `timestamps.py` の出力に注記 | ─ 引き続き手作業。矛盾語を隣接させる作法は上の「発見6」を参照 |

**本文レベルの解析は別ファイル。** この文書は15本の外形(章構成・尺・出典数・タイトル)の解析である。本文の話法については、後日入手した高再生台本4本の全文をもとに `script-analysis.md` で解析した。v3.2の変更の大半はそちらに由来する。
