# 直近1週間の実測 — 同ジャンル・弱小Chの突破テーマ

**取得日 2026年8月25日。対象期間は直近1週間(YouTube検索の「今週」フィルタ)。**

## 何をどう測ったか

vidIQ が無いので、yt-dlp で自前に取った。手順は再現可能である。

1. **検索42クエリ**を「今週」フィルタ付きで叩き、3,489本を収集
2. **ジャンル判定**でふるいにかけた。条件は「なぜ〜のか」型のタイトル、または学問タグ付き、かつ**7分以上**(短尺と切り抜きを除く)。反応集・海外の反応・実況・切り抜きは除外
3. 残った**544チャンネル**の一覧を取得(登録者数と直近25本の再生数)
4. **自Ch比**を計算した。その動画の再生数 ÷ そのチャンネルの直近動画の再生数の中央値

**「自Ch比」を主指標にした理由。** 弱小Chでは絶対再生数がそもそも小さいので、絶対値で並べると大手しか出てこない。**同じチャンネルが同じ型・同じ尺で出した他の動画と比べて何倍跳ねたか**を見れば、**チャンネル力を打ち消してテーマの効果だけを取り出せる。**

最終的な分析対象は **524本 / 352チャンネル**。

生データは `raw/channels.json`、`raw/raw_flat.json`、`raw/raw_flat2.json` に置いた。

## 4. 何が効いているのか

上位に共通しているのは、**当事者性が100パーセントで、しかも当人に反証できない題**である。

- **3歳より前の記憶がない** ── 全員が該当し、全員が確認できない
- **子どもは親の愛よりも何を記憶しているか** ── 親の側も子の側も当事者
- **本当に頭がいい人の特徴** ── 自分がどちらか分からないから最後まで見る

「なぜ、低収入から抜け出せないのか」(418回)との差はここにある。**低収入は、自分が該当するかどうかを視聴者が瞬時に判定できてしまう。** 該当しない人はクリックしない。**幼少期の記憶は、誰も自分を除外できない。**

## 5. この結果の限界(重要)

**過信しないこと。以下はすべて実測の弱点である。**

1. **期間が1週間しかない。** 記憶・幼少期は n=10、知能・能力は n=19。**この本数では統計的な検定に意味がない**
2. **知能・能力の上位は1チャンネルに偏っている。** 「浮き世の解剖ラボ」(登録158人)が4本を占め、そのすべてが平常73回に対する数千回である。**自Ch比では49倍に見えるが、絶対値では3,600回で、バズとは呼べない**
3. **自Ch比は分母が小さいと暴れる。** 平常2回の動画が14回になれば7倍になる
4. **YouTubeの検索が返す再生数は丸められている**(31,000、49,000のように)
5. **テーマ以外の要因を分離できていない。** サムネ、投稿時刻、アルゴリズムの偶然を切り分ける手段がない
6. **参照93本の結論と一部で食い違う。** `titles.md` では**恋愛と性が中央値125,000で最上位**だったが、今週の弱小Chでは**恋愛市場が最下位(0.67倍)**である

**6番の食い違いは、矛盾ではなく別のことを測っている。** `titles.md` は確立したチャンネルの**絶対再生数の天井**を測り、この表は弱小Chの**突破しやすさ**を測っている。**恋愛は天井が高いが、今週の投稿本数が42本といちばん混んでいる。** 記憶・幼少期は10本しか出ていない。

---

## 6. 使い方

**この表は「次に何を作るか」の入力であって、規律ではない。**

- **記憶・幼少期を最優先の候補に入れる。** 参照93本で扱われた記憶の題は「記憶の美化」1本だけで、**幼児期健忘・幼少期の環境・親の記憶はほぼ空いている**
- **知能・能力は二番手。** ただし本チャンネルは既に「会議の沈黙」で近い題を扱っている
- **恋愛は落とさない。** 天井は依然としていちばん高い。**混んでいる分、題の切り口で差を付ける必要があるという話である**
- **来週また取り直す。** `raw/` のスクリプトで再現できる

**そして絶対規律は変わらない。** テーマがどれだけ有望でも、**実在の研究と統計だけを使う。** 幼児期健忘は神経科学の係争地で、断定的な説明が出回っているが、**確定していない部分は確定していないと書く。**

# 追補 — トレンド側の実測(同日)

前半は**ジャンルを固定して弱小Chの突破率**を測った。ここでは逆に、**ジャンルを外して「いま何が伸びているか」**を測る。

**手順。** YouTube検索を「今週アップ」かつ「再生数順」(`sp=CAMSBAgDEAE`)で叩いた。40クエリ、1,135本を収集。日本語・5分以上・5万回以上に絞ると18本が残った。生データは `raw/trend.json` と `raw/trend2.json`、スクリプトは `tools/scan_trend_global.py` と `tools/scan_trend_jp.py`。

## 3. いちばん重要な結論 ── トレンドと突破率は逆を向いている

**今週トレンド性のある題を、前半で測った区分に当てはめると、こうなる。**

| トレンドの題 | 属する区分 | その区分の自Ch比中央値 | 突破率 |
|---|---|---|---|
| 外国人労働者・移民 | 社会制度 | 0.96倍 | 19パーセント |
| 旅に出ない日本人 | 社会制度 | 0.96倍 | 19パーセント |
| 投資しない日本人 | 金と階層 | 0.79倍 | 15パーセント |
| 日本語の不思議 | その他(参照Chでは「モノと現象」で最下位) | 0.79倍 | 7パーセント |
| **AIと人間の能力** | **知能・能力** | **2.44倍** | **42パーセント** |

**トレンドの熱と、弱小Chの突破しやすさは、ほとんど反対を向いている。** 理由は単純で、**熱い題には大手が全部入ってくる。** 外国人問題はABEMAと虎ノ門が79分と36分の尺で押さえており、弱小Chが同じ土俵に乗る意味は薄い。

**唯一の交差点がAIである。** 世界規模でいちばん熱く、しかも**知能・能力**という前半で第2位だった区分に落ちる。

## 4. トレンドに乗るときの原則

**ニュースそのものを追わない。** 参照93本にニュース起点の回は一本も無く、すべて恒久的な題である。**17分の調査型解説は制作に時間がかかり、旬が過ぎると死ぬ。**

**乗るなら、旬の話題の下にある恒久的な構造のほうを解剖する。** そうすれば、いま検索需要を拾い、なおかつ半年後も生きている。

| ✗ 旬に乗る | ✓ 旬の下の構造に乗る |
|---|---|
| AIバブルはいつ弾けるのか | なぜバブルは、中にいる人に見えないのか |
| 外国人労働者を受け入れるべきか | なぜ人手不足は、賃金が上がっても消えないのか |
| 日本人は旅行しなくなった | なぜ休みが増えるほど、人は出かけなくなるのか |

## 5. この追補の限界

- **1日の断面である。** 来週には別の話題が上に来る
- **YouTube検索の再生数順は、検索語に強く依存する。** 40クエリで拾えたものしか見えていない
- **「トレンドと突破率が逆」は今週の18本から言っている。** 恒常的な法則として扱わない
