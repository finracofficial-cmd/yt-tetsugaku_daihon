# 台本の型 v4.0 — 参照4本から導出した構造

**この文書は構成と分量の唯一の正である。** 工程2の前に必ず読む。

---

## 0. v3.2までとの違いを先に書く

v3.2までの「41ビート固定順」は、**v3.1の指示書から引き継いだもので、参照チャンネルの台本には存在しない構造だった。** 参照4本を文単位で解析したところ、4本に共通する固定の順序は無かった。あったのは、**共通する要素**と、**その分布**である。

導出した順序の実測(位置は本文の何パーセント地点か)。

```
01  7%研究 → 10%問い → 15%情景 → 29%問い → 32%翻訳 → 45%研究 → 52%翻訳 → 60%反論 → 70%研究 → 88%回帰 → 98%着地
02  5%問い → 15%情景 → 19%翻訳 → 21%研究 → 28%限界 → 37%回収 → 48%問い → 61%研究 → 78%問い → 90%回帰 → 99%着地
03  0%情景 → 10%問い → 12%研究 → 21%限界 → 36%情景 → 42%回収 → 49%限界 → 67%回収 → 73%情景 → 90%回帰 → 98%着地
04  5%限界 → 14%巨視 → 16%反論 → 25%翻訳 → 33%回収 → 37%問い → 52%反論 → 68%情景 → 83%回帰 → 89%回収 → 98%着地
```

**一致しているのは両端だけである。** 冒頭は情景か逆説、83〜91パーセント地点で冒頭に戻り、98パーセントで手渡して終わる。中間の並びは毎回ちがう。

したがってv4.0は、**固定順を捨て、6つの錨と分布のノルマに置き換える。**

## 1. 実測(参照4本 対 自作6本)

同一の正規表現で両方を測った数字である。

| 指標 | 参照4本 | 自作6本(v3.2まで) | 判定 |
|---|---|---|---|
| 総字数 | 4,992〜7,064 | 6,983〜7,583 | 長い |
| 総文数 | 175〜206 | 221〜289 | **1.3倍。ここが最大の差** |
| 最初の実データの位置 | 7・8・7・17パーセント | 0〜5パーセント | **早すぎる** |
| **研究文の最長連続** | **1〜2文** | **2〜4文** | **塊が大きい** |
| **研究の出てこない十分位** | **1〜4区間** | **0〜2区間** | **休みが無い** |
| 冒頭への回帰 | 88・90・90・91パーセント(全本) | 92パーセント(1本のみ実行) | 位置は合っている |
| メタ発話(1区間あたり) | 0.09 | 0.82 | 修正済み |
| 承認句のある段落 | 0.18 | 0.55 | 過剰 |
| 二人称 | 10・11・12・15回 | ばらつく | 下限8回 |

**いちばん効いている差は、研究の数ではない。** 参照は10区間のうち1〜4区間を、研究も数値も一つも出さずに、情景と地の文だけで進んでいる。自作はほぼ全区間にデータを敷き詰めていた。**聞き手が休める区間が無い台本は、密度が高いのではなく、ただ疲れる。**

## 2. 三層と六つの錨

段落は40が既定(36〜42まで許容)。**1段落=1つの仕事。**

```
開幕  P1〜P5    約820字   0〜13パーセント
展開  P6〜P33   約4,540字 13〜85パーセント
着地  P34〜P40  約940字   85〜100パーセント
```

固定するのは次の6箇所だけである。**それ以外の順序は自由に組んでよい。**

| 錨 | 位置 | 中身 | 監査 |
|---|---|---|---|
| ① 開幕の一撃 | P1 | 情景か逆説の一行。**数字で始めない** | FAIL |
| ② 最初の実データ | P3〜P7 | 7〜17パーセント地点。ここまでは情景と逆説で引っぱる | WARN |
| ③ 問いと学問の宣言 | P5〜P6 | 中心の問い。**メタ発話が許される唯一の場所** | WARN |
| ④ 冒頭への回帰 | P34〜P36 | 冒頭の情景そのものに戻る。「振り返ろう」とは言わない | FAIL |
| ⑤ 手渡し | P39 | 救済・和解・返却・問いのいずれか。**断罪しない** | WARN |
| ⑥ シグネチャ | P40 | 「そんなことまで、また解剖してしまいました。」 | FAIL |

## 3. 開幕(P1〜P5、約820字)

参照4本の冒頭を、そのまま型として使える。

| 本 | 型 | 冒頭 |
|---|---|---|
| 01 | 逆説 | 自分の口から頭がいいという人間を、我々はなぜか信じない |
| 02 | 情景 | 土曜日の夕方6時。東京銀座のホテルラウンジ |
| 03 | 情景 | 電車の中、吊り革に捕まったあなたの正面に、入れ墨の入った男が座っている |
| 04 | 逆説 | 嘘をつくなとどんな親も子供に言う。ところがもし本当に嘘をつけなかったら |

**P1** 情景か逆説を一行で。数字を入れない。

**P2** その情景を二人称で広げる。あるいは逆説の食い違いを一行で言い切る。

**P3〜P4** ここで初めて実データを出す。現象の広がりを、丸めない数字で。そして視聴者が最初に思いつく通説を、一度きちんと立てる。**通説を雑に立てると、崩したときの快感が出ない。**

**P5** 中心の問いを置き、どの学問で解剖するかを宣言する。

> ここでのみ許される言い方 ──「今日はそれを、心理学と神経科学から解剖してみたい」

**P5を過ぎたら、二度と設計図を音読しない。**

## 4. 展開(P6〜P33、約4,540字)

### 4-1 素材の周回

固定の順序は無い。あるのは**周回**である。1周は3〜4段落。**7〜9周**で展開部を埋める。

```
1周 =  ① 素材を出す(研究・統計・事例・歴史・種間比較のいずれか)
       ② その意味を地の文で引き受ける(ここが本体。データより長くてよい)
       ③ 次の周へ渡す一行(「ところが」「さらに精密な実験がある」「一方」)
```

**①は2文まで。3文以上続けない。** 参照4本で研究文が3文以上連続した箇所は一つも無い(最長2文)。データを続けたくなったら、間に②を挟んで割る。

### 4-2 展開部に配るノルマ

28段落のあいだに、次を分散させる。**位置は自由。連続させない。**

| 要素 | 回数 | 備考 |
|---|---|---|
| 素材の周回 | 7〜9周 | 上記 |
| **研究ゼロの区間** | **2箇所以上、各2〜4段落** | **v4.0の新ノルマ。参照は10区間中1〜4区間が研究ゼロ** |
| 中盤の情景 | 2〜3回 | **冒頭とは別の場面にする。** 冒頭への回帰は着地帯でだけ起こす |
| 想定反論 → 越え | 3回以上 | うち1回はP28以降に残す(参照4本中3本が終盤にも反論を持つ) |
| 現代語への翻訳 | 3回以上(目安5) | 抽象概念を出したその場で、視聴者が知っている具体物に対応させる |
| 限界と反証 | 1〜2回 | 自分が出した研究を自分で削る |
| 巨視化 | 1〜2回 | 進化史・歴史反転・制度の発明のいずれか |
| 非対称性の解剖 | 1回 | 「Aは成り立つが、Bは成り立たない」。金が絡むなら帳簿の形をとる |
| 飛び道具 | 1回 | テーマと一見無関係な領域から、同じ構造を持つ研究や事例 |
| 疑問文で終わる段落 | 3回以上 | 位置は自由 |

### 4-3 研究ゼロの区間の作り方

これが v4.0 でいちばん重要な新しい規律である。**2〜4段落つづけて、研究も統計も数字も出さない区間を、展開部に2箇所つくる。** そこで書くもの。

- 冒頭とは別の、日常の情景を二人称で
- 直前に出した研究の意味を、たとえ話だけで転がす
- 視聴者の反論を代弁し、認め、越える
- 「その仕組みが、あなたの一日のどこに現れるか」を具体物で並べる

**この区間は密度を落とすのではない。** 数字の密度を、情景と論理の密度に置き換える。参照4本が長い尺を保っているのはこの交代があるからで、データを均等に敷き詰めると、聞き手は5分で満腹になる。

## 5. 着地(P34〜P40、約940字)

参照4本すべてが同じ運動をしている。**83〜91パーセント地点で、冒頭の情景に帰る。**

| 段落 | 仕事 |
|---|---|
| **P34〜P35** | **冒頭の情景そのものに戻る。** 同じ場面、同じ人物、同じ時刻。「ここまでを振り返ろう」とは絶対に言わない。**戻ったあとで、その場面が最初とは違って見えることを示す** |
| P36 | 発見を並べ直す。ここで初めて、解剖の結果が一続きの線になる |
| P37 | 最後の反論を越える。展開部でいちばん強い反対意見を、ここでもう一度出して越える |
| P38 | 代償か、巨視の一撃。この構造が人間から奪っているものを、数字か歴史で一発 |
| P39 | **手渡す。** 4型のいずれか(下記) |
| P40 | シグネチャ。ここだけ敬語 |

### 着地の4型

**参照4本のいずれも、視聴者に矛先を返していない。**「あなたもその構造の中にいる」と指を突きつけた回は一本も無い。

| 型 | 何を渡すか | 例 |
|---|---|---|
| 救済 | 同じ構造の中で楽になれる手 | 「照合の回数を減らすだけで、その差は縮む」 |
| 和解 | 対立していた二者が同じ仕組みの産物だったと示す | 「二人は敵ではなく、同じ装置の別の出口にいた」 |
| 返却 | 奪われていたものに名前をつけて返す | 「それは怠惰ではない。名前のある生理現象だった」 |
| 問い | 答えを出さず、持ち帰れる問いを渡す | 「明日あなたが選ぶのは、どちらだろうか」 |

**矛先を返された視聴者は動画を人に勧めない。武器を手渡された視聴者は勧める。**

## 6. 段落の重さ

参照の文字起こしには段落の区切りが無いため、**段落の長さは参照から導出できない。以下は本チャンネルの自前の目安であり、監査もWARNに留めている。**

- 中央値 150〜180字
- 200字以上の重量段落を**4段落以上**。主役研究を手順から描く段落がこれにあたる
- 40字未満の一撃の一行は、リズムとして有効。ただし多用しない
- 400字を超えたら分割を検討する

## 7. やってはならないこと(実測で裏が取れているものだけ)

1. **数字で始める。** 参照4本のいずれも数字で始まっていない
2. **研究文を3文以上続ける。** 参照の最長は2文
3. **全区間にデータを敷き詰める。** 参照は1〜4区間が研究ゼロ
4. **設計図を音読する。** 参照は開幕に1回だけ。以降ゼロ(`style.md` 冒頭の禁止表)
5. **反論のたびに承認句を置く。** 参照は反論3回に対し明示的な承認およそ1回
6. **「振り返ろう」で着地に入る。** 参照は冒頭の情景に戻ることで同じ仕事をしている
7. **オチで視聴者を断罪する。** 参照4本ともゼロ
8. **総文数を230文以上にする。** 参照は175〜206文

v3.2までの「41ビート表」は廃止する。代わりに次の2枚を出す。

**表1 錨(6行)**

| 錨 | 段落 | 何を置くか |

**表2 展開部の周回(7〜9行)+ 研究ゼロ区間(2行以上)**

| 周 | 段落 | 素材(台帳の行番号) | 意味づけで書くこと | この周に載せる装置 |
