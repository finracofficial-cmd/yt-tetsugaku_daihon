# 台本の型 v5.0 — 参照チャンネル全92本から較正した構造

**この文書は構成と分量の唯一の正である。** 工程2の前に必ず読む。

---

## 0. まず、この型が何を保証しないか

参照チャンネルの全92本について、**18個の構造指標と再生数の順位相関を取った。多重比較の補正後に有意なものは一つも無かった**(最大 rho=+0.273、補正後の基準は p<0.0028)。

**つまり、ここに書いてあるしきい値は「再生数を上げる条件」ではない。** 参照チャンネルの文体に寄せるための帯である。市場リサーチ(`knowledge/reference-channel/market-research.md`)では**テーマの効果が10〜100倍**だったのに対し、構造の効果はノイズと区別がつかなかった。

再生数を動かすのはテーマとタイトルである。この文書が担保するのは、**同じ声で書けること**だけである。それでも型が要るのは、型が無いと毎回ぶれるからで、伸びるからではない。

---

## 1. v4.0までの誤りと、その原因

v4.0までのしきい値は、**手作業で書き起こした4本**から導いていた。全92本の自動字幕を取得して測り直したところ、**次の3つは参照チャンネルの実測と逆を向いていた。**

| v4.0で書いていた規律 | n=4での見え方 | n=92の実測 | 判定 |
|---|---|---|---|
| 最初の実データは7〜17パーセント地点。そこまで情景で引っぱる | 7・8・7・17% | **中央値3.3%** / p90でも12% | **逆。むしろ早く出す** |
| 研究文を3文以上続けない | 最長1〜2文 | **中央値3文** / p90が5文 / 最大8文 | **逆。3文は普通** |
| 研究ゼロの区間を2箇所つくる | 1〜4区間 | **中央値1区間** / 92本中22本は0区間 | **必須ではない** |

原因ははっきりしている。**n=4で、しかもその4本は「バズった回」として選ばれた偏った標本だった。** 標本の端の値を、規律として書いてしまった。

**取り下げた主張はもう一つある。** v3.2で「参照は本編でメタ発話をしない(1区間あたり0.09)」と断定し、これを最優先の規律に据えた。全92本ではメタ発話は**中央値1件・p90が3件・最大6件**あり、しかも**18指標のうち再生数との相関が最も強かったのがこの指標で、符号は正だった**(rho=+0.273、補正後は有意でない)。「多いほど伸びる」とは言えないが、**「少ないほど良い」の根拠も無い。**

## 3. 三層と五つの錨

段落は40が既定(36〜42まで許容)。**1段落=1つの仕事。**

```
開幕  P1〜P5    約820字   0〜13パーセント
展開  P6〜P33   約4,640字 13〜85パーセント
着地  P34〜P40  約940字   85〜100パーセント
```

固定するのは次の5箇所だけである。**それ以外の順序は自由に組んでよい。**

| 錨 | 位置 | 中身 | 監査 |
|---|---|---|---|
| ① 開幕の一撃 | P1 | 情景か逆説の一行が多数派。**数字始まりも10パーセントある** | WARN |
| ② 問いと学問の宣言 | P5〜P6 | 中心の問い | WARN |
| ③ 冒頭への回帰 | P33〜P37 | 冒頭の情景そのものに戻る。**参照でも実行は51パーセント。必須ではない** | WARN |
| ④ 手渡し | P39 | 救済・和解・返却・問いのいずれか。**断罪しない** | WARN |
| ⑤ シグネチャ | P40 | 「そんなことまで、また解剖してしまいました。」 | FAIL |

> **v4.0にあった「最初の実データは P3〜P7」という錨は削除した。** 参照の中央値が3.3パーセント地点だったため、位置を縛る理由が無い。**実データは最初の段落から出してよい。**

## 4. 開幕(P1〜P5、約820字)

参照の上位回の冒頭を、そのまま型として使える。

| 型 | 冒頭 |
|---|---|
| 逆説 | 自分の口から頭がいいという人間を、我々はなぜか信じない |
| 情景 | 土曜日の夕方6時。東京銀座のホテルラウンジ |
| 情景 | 電車の中、吊り革に捕まったあなたの正面に、入れ墨の入った男が座っている |
| 逆説 | 嘘をつくなとどんな親も子供に言う。ところがもし本当に嘘をつけなかったら |

**P1** 情景か逆説を一行で。**数字を入れてもよい。** 参照92本の第1文は40パーセントが数字を含み、10パーセントは数字で始まっている(「2022年度、日本の企業が交際費として計上した金額は」のような統計始まりの回も実在する)。**v4.0までの「冒頭に数字を使わない」はn=4の思い込みで、取り下げた。**

**P2** その情景を二人称で広げる。あるいは逆説の食い違いを一行で言い切る。

**P3〜P4** **実データを出してよい。** 現象の広がりを、丸めない数字で。そして視聴者が最初に思いつく通説を、一度きちんと立てる。**通説を雑に立てると、崩したときの快感が出ない。**

**P5** 中心の問いを置き、どの学問で解剖するかを宣言する。

## 5. 展開(P6〜P33、約4,640字)

### 5-1 素材の周回

固定の順序は無い。あるのは**周回**である。1周は3〜4段落。**7〜9周**で展開部を埋める。

```
1周 =  ① 素材を出す(研究・統計・事例・歴史・種間比較のいずれか)
       ② その意味を地の文で引き受ける
       ③ 次の周へ渡す一行(「ところが」「さらに精密な実験がある」「一方」)
```

**①は続けて5文まで。** 参照の中央値は3文、p90が5文である。6文以上でWARN、9文以上でFAIL。

### 5-2 展開部に配るもの

28段落のあいだに分散させる。**位置は自由。**

| 要素 | 目安 | 出所 |
|---|---|---|
| 素材の周回 | 7〜9周 | 自前 |
| 中盤の情景 | 3回(下限1回) | 参照の中央値 |
| 想定反論 → 越え | 3回以上、うち1回はP28以降 | 参照の中央値と一致 |
| 疑問文で終わる段落 | 8回(下限4回) | 参照の中央値は疑問文12文 |
| 巨視化 | 4回以上 | 参照の中央値6件 |
| **現代語への翻訳** | **3回以上(目安5)** | **自前。参照の中央値は1回で、意図的に多く取る** |
| **限界と反証** | **1回以上** | **自前。参照の中央値は0回** |
| 非対称性の解剖 | 1回 | 自前 |
| 飛び道具 | 1回 | 自前 |

### 5-3 「研究ゼロの区間」について(v4.0の規律を取り下げる)

v4.0では「研究も数値も出てこない区間を2箇所つくる」を最重要の新規律に据えた。**全92本では中央値1区間、92本中22本は0区間で、規律として書けるほどの傾向は無かった。**

ただし、**中盤の情景を3回入れる**というノルマを守れば、結果として研究の薄い区間は自然にできる。**「意識して2箇所空ける」ではなく「情景と意味づけの分だけ結果的に空く」**が正しい。監査もWARNすら出さず、区間数を報告するだけにした。

## 6. 着地(P34〜P40、約940字)

| 段落 | 仕事 |
|---|---|
| P34〜P35 | **冒頭の情景に戻る。** 同じ場面、同じ人物、同じ時刻。「ここまでを振り返ろう」とは言わない。**戻ったあとで、その場面が最初とは違って見えることを示す**。参照でも実行は51パーセントなので、噛み合わなければ無理に入れない |
| P36 | 発見を並べ直す |
| P37 | 最後の反論を越える |
| P38 | 代償か、巨視の一撃 |
| P39 | **手渡す。** 4型のいずれか(下記) |
| P40 | シグネチャ。ここだけ敬語 |

### 着地の4型

| 型 | 何を渡すか | 例 |
|---|---|---|
| 救済 | 同じ構造の中で楽になれる手 | 「照合の回数を減らすだけで、その差は縮む」 |
| 和解 | 対立していた二者が同じ仕組みの産物だったと示す | 「二人は敵ではなく、同じ装置の別の出口にいた」 |
| 返却 | 奪われていたものに名前をつけて返す | 「それは怠惰ではない。名前のある生理現象だった」 |
| 問い | 答えを出さず、持ち帰れる問いを渡す | 「明日あなたが選ぶのは、どちらだろうか」 |

**視聴者に矛先を返さない。** これは実測ではなく本チャンネルの方針である。矛先を返された視聴者は動画を人に勧めない。

## 7. 段落の重さ

**段落の長さは参照から導出できない。** 自動字幕にも手作業の書き起こしにも段落の区切りが無いためである。以下は自前の目安で、監査もWARNに留めている。

- 中央値 150〜180字
- 200字以上の重量段落を**4段落以上**(FAIL)。主役研究を手順から描く段落
- 40字未満の一撃の一行は、リズムとして有効。多用しない
- 400字を超えたら分割を検討する

## 8. やってはならないこと

**実測で裏が取れているもの。**

1. **総字数を9,000字超または4,000字未満にする。** 参照92本は3,043〜9,735字
2. **総文数を290文以上にする。** 参照92本の最大が288文
3. **メタ発話を7件以上入れる。** 参照92本の最大が6件

**本チャンネル自前の規律(参照の実測とは意図的にずらす)。**

4. **オチで視聴者を断罪する**
5. **実在の個人・団体を悪玉にする**
6. **限界と反証を書かない**(参照の中央値は0件だが、こちらは必須)
7. **現代語への翻訳が3箇所未満**(参照の中央値は1件だが、こちらは意図的に多く取る)
8. **繋ぎ文で字数を水増しする**
