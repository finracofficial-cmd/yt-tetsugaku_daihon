# 41ビート設計図

この台本の骨格そのもの。**1ビート=1段落**。数字は目標字数。

厚みと密度は執筆時の努力ではなく、この工程そのものが物理的に保証する。ビートを飛ばした台本は、どれだけ文章が上手くても不合格になる。

## ブロックD:非対称性の解剖(ビート21〜27/1,240字)

**このブロックは省略不可。** この動画全体を一行に圧縮したときの形が、ここで作られる。

※旧仕様ではここを「帳簿=金の流れ」に固定していたが、高再生台本4本にはいずれも金の流れの解剖が存在しなかった。**帳簿は非対称性の一形態である。** テーマが商品・市場・制度なら帳簿の形をとり、テーマが感情や認知なら別の形をとる。

求めるのは「**Aは成り立つが、Bは成り立たない**」という、揃っていないものの発見である。

```
自己申告はタダ  → だから信用されない / コストを払った信号だけが信用される
絶対値の幸福は2年で順応する / 相対的な比較だけは生涯順応しない
好きと嫌いは同じ神経回路で燃える / 本当の反対は無関心
価格は原価に対応していない / それでも買い手は原価を買っていると思っている   ← 帳簿型
```

### ビート39の4型 ── 視聴者を断罪してはならない

※旧仕様の「鏡のオチ ── 矛先を視聴者に返す」は、高再生台本4本の作法と逆を向いていた。**4本とも、視聴者に武器か、赦しか、問いを手渡して終わっている。**「あなたもその構造の中にいる」と指を突きつけた例は一本もない。矛先を返された視聴者は動画を人に勧めない。

| 型 | 形 | 例 |
|---|---|---|
| **救済型** | すでにあなたは持っている、と告げる | 「もしあなたにその経験があるのなら、すでにその最強の武器を手に入れている」 |
| **和解型** | 勝ち負けの外に出口を置く | 「人生はどちらが勝ったかではなく、どちらを選んでも残るもう片方の影とどう向き合うかの問題なのかもしれない」 |
| **返却型** | 判断せず、観察だけを手渡す | 「それは好きだからかもしれない。だが、まだ閉じていないタブがひとつ開きっぱなしなだけかもしれない。どちらにせよ、あなたはその人に無関心ではない。そのことだけは確かだ」 |
| **問い型** | 最後を問いで開いたまま閉じる | 「あなたが今日つく次の嘘は、誰かを傷つけるためのものだろうか。それとも誰かとの関係を、そっとつなぎ止めるためのものだろうか」 |

## 監査の最重要項目

### 重量級ビート

**ビート10・17・24・30・37。この5つが200字を下回っていたら、その台本は不合格。**

順に「最初の山場」「飛び道具」「非対称の核心」「巨視化の反転」「全回収」であり、動画の格を決める。字数不足はほぼ例外なく、この5つのどれかで素材が足りていないことを意味する。増築するならここから。

### ブロック末尾の疑問文

**ビート13・20・27・32・36の末尾は必ず疑問文で終える。**

章の切れ目は視聴者が最も離脱する瞬間である。そこを最も引きの強い瞬間に変えるのがオープンループの役割。答えは必ず次ブロックに持ち越す。

### 引き込みの3装置(※新規)

高再生台本4本を貫いていた技法。**これが欠けている台本は、正確でも面白くない。**

| 装置 | 既定の位置 | 判定 | 参照4本の実測 |
|---|---|---|---|
| **想定反論 → 一部承認 → 反転** | ビート12・26 | **3回未満でFAIL**。ブロックC・Eにも自由に足してよい | 3・4・5・12回 |
| **現代語への翻訳** | ビート11、ビート17直後 | **3箇所未満でFAIL、5箇所が目安** | 3・6・1・5箇所 |
| **二人称の呼びかけ** | ビート2・19・25・27・39 | 「あなた」「我々」「〜してみてほしい」の合計が**8回未満でFAIL** | 11・15・10・12回 |
| **限界と反証** | ビート16 | 機械監査はWARN。**自前の規律としては必須** | 4本中1本のみ |

> **「あなた」の多用は必須ではない。** 最高再生の01は「あなた」を2回しか使わず、代わりに「我々」「私たち」で7回括っている。必須なのは聞き手を文の中に入れることであって、特定の代名詞ではない。

### ミクロ情景

**ビート2・19・27・35の4か所。** 場所+時刻+人物+動作+具体的な数字。**三人称で書かない。**

聴覚だけのAI音声動画において、この情景描写が「映像」の代わりを果たしている。抽象論が2〜3段落続いたら必ず挟む。
