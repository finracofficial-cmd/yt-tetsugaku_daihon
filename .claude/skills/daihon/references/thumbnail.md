# サムネイル案の作り方

参照チャンネル「考えすぎる葦」のサムネ**実物15枚を全枚解析**して抽出した仕様。元データと根拠は `knowledge/reference-channel/thumbnails.md` にある。

---

## 大前提:サムネ文言は、タイトルではない

**実物15枚すべてで、サムネの文字はタイトルと別物である。** タイトルを縮めたものですらない。**別に作った短い見出し語**が載っている。

| タイトル | サムネ文言 |
|---|---|
| なぜ面白い人は、イケメンでなくてもモテるのか | ユーモアは何と相関するか |
| なぜ国家は"違法"を見て見ぬふりするのか | なぜ捕まらない |
| なぜ現代人は、"働きアリ"になりきれないのか | 月曜日の蟻 |
| なぜ人は、歳を取るほど丸くなるのか | 成熟という名の去勢 |

**字数は5〜14字、中央値10字。全枚が2行組み。** タイトルの半分以下である。20字を超える文言を置くと、スマホの一覧で読めなくなる。

だから、**サムネ案を作る作業は「文言を発明する作業」であり、絵はその次に来る。** 絵から考えてはならない。

---

## 手順1:サムネ文言を、4つの型で3つ作る

### 型1 「◯◯のパラドックス」型

> 搾取のパラドックス / 港区女子のパラドックス2 / 客寄せパンダのパラドックス / 聖地巡礼のパラドックス

シリーズ化されたブランド語。**最も安全で、最も再利用が効く。** 上段に対象を赤、下段に「パラドックス」を白か紺。台本のテーマ名を頭に付けるだけで成立する。

### 型2 造語・比喩の名詞型

> 終生浮遊人 / 成熟という名の去勢 / 月曜日の蟻 / リビングデッド企業の呼び声 / 武器の収斂進化

**台本のビート38(逆説の再定義)を、詩的な名詞句に圧縮する。** 意味が半分しか分からないので、確かめたくてクリックが起きる。5〜13字。格は上がるが、外すと何の動画か分からない。

### 型3 疑問文型

> ユーモアは何と相関するか / なぜ捕まらない / 日本で一番多い店は / 脳の大きさ ≠ 知性

**実測の最高再生149,196回はこの型。** コツは、タイトルの疑問文をそのまま短くしないこと。**もっと素朴で、子供が聞くような問いに落とす。**

「なぜ国家は違法を見て見ぬふりするのか」→「なぜ捕まらない」

### 型4 映画・作品パロディ型

> その男、色欲につき / リビングデッド企業の呼び声

既存作品の題を1語だけ差し替える。**絵柄もパロディ元に寄せる。** 当たると強いが、元ネタを知らない層には効かない。台本と自然に噛み合うときだけ使う。

**3案は、この4型のうち3つを使う。** 同じ型で3つ作ってはならない。型1は毎回入れてよい(シリーズとして蓄積するため)。

---

## 手順2:文字の組み方を決める

全15枚が例外なく守っている法則。

1. **文字は必ず2色で組む。** 1色だけの例は1枚もない
2. **赤(または朱・臙脂)を必ず入れる。** 15枚中14枚。残る1枚もピンク
3. **もう1色は、白・紺・金・水色のどれか**
4. **上下2行。それぞれ5〜7字**
5. 文字には縁取りかテクスチャを乗せる(ひび割れ、かすれ、紙の粒子、袋文字)
6. **左寄せ。** 実測12枚/15枚。被写体は右に置く
7. 記号(≠、?)を使うときは、文字と同じか倍の大きさにする

---

## 手順3:絵のプロンプトを書く

### 文字は画像生成に入れさせない

参照チャンネルも**絵を作ってから文字を乗せている。** 根拠は、書体が完全に均一で1文字も崩れていないこと、袋文字とテクスチャが輪郭に正確に沿っていること、パラドックスの4枚で同じ書体が再利用されていることである。画像生成の日本語出力では起こりえない品質である。

したがってプロンプトは**文字なしで書き、文字を乗せる余白を明示的に指定する。** そのうえで、乗せる文言と色と書体を別記する。ChatGPTに短い日本語を描かせることも可能ではあるが、崩れる前提の賭けになるので既定にはしない。

### 画風は5系統から選ぶ

| 系統 | 指定の書き方 | 向くテーマ |
|---|---|---|
| **AIダークイラスト** | 紫と赤の暗い画面。人物の顔を右にクローズアップ。細密で情報量の多い劇画調 | 欲望、依存、搾取、信仰。実測で最多の6枚 |
| **フラットベクター図解** | オフホワイト背景。黒い棒人間、点線の円、薄いドットのグリッド、水色の小円 | 相関、比較、分類。**実測の最高再生がこの系統** |
| **白黒シルエット図鑑** | 白背景に黒の細密シルエットを大量に配置。中央に赤の極太文字を重ねる | 進化、収斂、歴史の並列 |
| **実写風フォト** | 夜。人物のクローズアップ。カメラ目線 | 俗な入口が強く、人間が主役のとき |
| **和風レトロ絵巻** | 生成り色の紙、墨の線画、朱の毛筆、罫の枠 | 日本の制度、風習、身体 |

### プロンプトに必ず書くこと

- **余白の指定**。書かないと画面が絵で埋まり、文字が乗らない
- **人物の数**。指定しないと群衆になる
- **配色は3色以内**。4色以上は濁る
- **画風は1つに固定**。「リアルかつイラスト風」のような両立指定は破綻する
- 実在の人物名を出さない(「アインシュタイン風の」までは可)

---

## 出力の書式

台本ごとに3案。各案に以下を書く。

```
【文言】(5〜14字。2行に割る)
【型】4つの文言型のどれか
【画風】5系統のどれか
【狙い】1行

■ ChatGPTに貼る本文(文字なし)
（16対9、YouTubeサムネイル用、文字を入れない旨）
（背景 / 被写体 / 配色 / 画風 / 余白 の5点)

■ 後から乗せる文字
1行目:（文言・色）
2行目:（文言・色）
書体:（極太ゴシック / 極太明朝 / 毛筆）
配置:（左寄せ など）
```
