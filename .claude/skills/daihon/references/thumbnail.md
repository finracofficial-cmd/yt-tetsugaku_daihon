# サムネイル案の作り方

参照チャンネル「考えすぎる葦」のサムネ**実物15枚を全枚解析**して抽出した仕様。元データと1枚ずつの文字の入れ方は `knowledge/reference-channel/thumbnails.md` にある。

---

## 前提1:サムネは、文字が主役で絵が背景である

15枚すべてで、画面の半分近くを文字が占めている。**したがって生成プロンプトには、描かせる文字を1行ずつ、色と書体つきで指定する。** 文字を指定しないプロンプトは、このチャンネルの型の設計図として成立しない。

## 前提2:サムネ文言は、タイトルではない

15枚すべてで、サムネの文字はタイトルと別物の短い見出し語である。タイトルを縮めたものですらない。

| タイトル(20〜29字) | サムネ文言(5〜14字) |
|---|---|
| なぜ面白い人は、イケメンでなくてもモテるのか | ユーモアは何と相関するか |
| なぜ国家は"違法"を見て見ぬふりするのか | なぜ捕まらない |
| なぜ現代人は、"働きアリ"になりきれないのか | 月曜日の蟻 |
| なぜ人は、歳を取るほど丸くなるのか | 成熟という名の去勢 |

**字数は5〜14字、中央値10字。** タイトルの半分以下である。

だから作業の順序は、**文言を発明する → 文字の組み方を決める → 絵のプロンプトに文字ごと書く**になる。絵から考えてはならない。

---

## 手順1:サムネ文言を、4つの型から3つ選んで作る

### 型1 「◯◯のパラドックス」型(実測4枚)

> 搾取のパラドックス / 港区女子のパラドックス2 / 客寄せパンダのパラドックス / 聖地巡礼のパラドックス

シリーズ化されたブランド語。**最も安全で、最も再利用が効く。** 台本のテーマ名を頭に付けるだけで成立する。

### 型2 造語・比喩の名詞型(実測5枚)

> 終生浮遊人 / 成熟という名の去勢 / 月曜日の蟻 / リビングデッド企業の呼び声 / 武器の収斂進化

**台本のビート38(逆説の再定義)を、詩的な名詞句に圧縮する。** 意味が半分しか分からないので確かめたくなる。格は上がるが、外すと何の動画か分からない。

### 型3 疑問文型(実測5枚)

> ユーモアは何と相関するか / なぜ捕まらない / 日本で一番多い店は / 脳の大きさ ≠ 知性

**実測の最高再生149,196回はこの型。** コツは、タイトルの疑問文をそのまま短くしないこと。**もっと素朴で、子供が聞くような問いに落とす。**

### 型4 映画・作品パロディ型(実測2枚)

> その男、色欲につき / リビングデッド企業の呼び声

既存作品の題を1語だけ差し替え、**絵柄もパロディ元に寄せる。** 台本と自然に噛み合うときだけ使う。

**3案は、この4型のうち3つを使う。** 型1は毎回入れてよい(シリーズとして蓄積するため)。

---

## 手順2:文字の組み方を決める(全15枚が守っている7法則)

1. **強調する1語を必ず決める。** 15枚すべてで、文言のうち**1語だけ**が赤(朱・紅・ピンク・金を含む)。残りは白か黒か紺。**赤くするのは台本の核心にあたる名詞か動詞**
2. **文字は2色以上で組む。** 単色の例は1枚もない
3. **助詞は小さく、別の色にする。**「の」「は」を主要語と同じ大きさ同じ色にした例は1枚もない
4. **2〜4段に割る。** 1行に流した例は15枚中1枚のみ。各段5〜7字
5. **縁取りかテクスチャを必ず付ける。** ひび割れ、かすれ、黒縁、墨だまり、押し出しの立体
6. **左寄せ。** 実測12枚/15枚。被写体は右に置く
7. **記号(≠、?)は文字の1〜2倍の大きさにする**

書体の実測は、ゴシック7枚・明朝5枚・毛筆3枚。**テーマが重いほど毛筆と明朝に寄る。**

## 手順3:絵の系統を5つから選ぶ

| 系統 | 指定の書き方 | 向くテーマ |
|---|---|---|
| **AIダークイラスト** | 紫と赤の暗い画面。人物の顔を右にクローズアップ。細密で情報量の多い劇画調 | 欲望、依存、搾取、信仰。実測最多の6枚 |
| **フラットベクター図解** | オフホワイト背景。黒い棒人間、点線の円、薄いドットのグリッド、水色の小円 | 相関、比較、分類。**実測の最高再生がこの系統** |
| **白黒シルエット図鑑** | 白背景に黒の細密シルエットを大量配置 | 進化、収斂、歴史の並列 |
| **実写風フォト** | 夜。人物のクローズアップ。カメラ目線 | 俗な入口が強く、人間が主役のとき |
| **和風レトロ絵巻** | 生成り色の紙、墨の線画、朱の毛筆、罫の枠 | 日本の制度、風習、身体 |

背景は**白系か暗黒系の二択**。中間の灰色やパステルの背景は1枚もない。

---

## 手順4:プロンプトを書く

### 必ず含める6項目

1. 16対9の横長、YouTubeサムネイル用であること
2. **画面内に描く文字**を、1行ずつ、色と大きさと書体で指定する
3. **指定した文字以外を一切描かせない指示**(これを書かないと崩れた偽の日本語が湧く)
4. 背景と被写体(人物は必ず人数を指定する)
5. 配色を3色以内で指定
6. 画風を1つに固定する

### 書式のひな型

```
16対9の横長画像を作ってください。YouTubeのサムネイル用です。

【画面に入れる文字】
画面の左半分に、次の日本語を縦に2段で、正確にこの通りに描いてください。
1段目「◯◯◯◯」赤。極太明朝。画面幅のおよそ4割。
2段目「◯◯◯◯◯」白。同じ書体でやや小さく。
文字には黒く太い縁取りと、細かなひび割れの質感を付けてください。
指定したこの文字以外の文字、記号、ロゴ、透かしは一切描かないでください。

【背景と被写体】
（背景 / 被写体 / 人数 / 姿勢 / 表情）
文字を置く左半分は、被写体を置かず、暗く落として文字が読める状態にしてください。

【配色と画風】
（3色以内 / 画風を1つ）
```

### 日本語が崩れたときの対処

生成結果の文字が崩れることはある。**プロンプトが間違っているのではなく、画像生成の限界である。** 対処は2つ。

1. 同じプロンプトで3回ほど引き直す。短い語ほど成功率が上がる
2. それでも駄目なら、【画面に入れる文字】の節を「文字は描かず、画面の左半分を余白のまま空けてください」に差し替えて絵だけを取り、文字をCanvaなどで乗せる

**どちらの道に進むにせよ、文字の指定は最初から書いておく。** そこが決まらないと、絵の側の余白と暗さが決められないからである。

---

## 出力の書式

台本ごとに3案。各案に以下を書く。

```
【文言】(5〜14字)
【型】4つの文言型のどれか
【画風】5系統のどれか
【狙い】1行

■ ChatGPTに貼る本文(文字を含む完成形)
（上のひな型に沿った全文)
```
