# 工程4:出力前の自己監査 v5.0

**不合格があれば、削るのではなく組み替えてから再確認する。**

> **しきい値は再生数の保証ではない。** 参照チャンネル全92本で18指標と再生数の順位相関を取ったが、多重比較の補正後に有意なものは一つも無かった。ここで測っているのは**参照チャンネルの文体に寄っているか**だけである。再生を動かすのはテーマとタイトルで、その根拠は `knowledge/reference-channel/market-research.md` にある。

## 第1段階:機械チェック

```bash
python3 tools/audit.py output/<ディレクトリ>/03_台本.txt
python3 tools/audit.py output/<ディレクトリ>/03_台本.txt --verbose   # 段落別の一覧
```

判定は2群に分かれる。**模倣**は参照92本の分布(p10〜p90)に合わせる帯、**自前**は参照とは意図的にずらしている本チャンネルの規律である。

### 量(模倣)

| 項目 | FAIL | 目安 | 参照92本 |
|---|---|---|---|
| 総字数 | 4,000未満 / 9,000超 | 5,600〜7,600字 | 中央値6,446字(3,043〜9,735) |
| 総文数 | 110未満 / 280超 | 150〜235文 | 中央値186文(93〜288) |
| 一文の長さの中央値 | — | 27〜37字 | 中央値31字 |
| 段落数 | 36未満 / 42超 | 40 | 測定不能(字幕に段落が無い) |
| 段落の長さ | — | 40〜400字 | 測定不能 |
| 重量段落(200字以上) | 4件未満 | 4件以上 | 測定不能 |
| 三層の字数配分 | — | 開幕820 / 展開4,640 / 着地940 | 自前 |

### 錨

| 項目 | 判定 | 参照92本 |
|---|---|---|
| 冒頭に数字 | **FAIL** | 上位回に例外なし |
| シグネチャ | **FAIL** | 固定 |
| 冒頭への回帰(P33〜P37) | WARN | **92本中47本(51パーセント)のみ実行。** 必須ではない |
| 着地の断罪 | WARN | 自前 |
| 最初の実データの位置 | 25パーセント超でWARN | 中央値3.3パーセント地点。**早くてよい** |

### 分布(模倣)

| 項目 | 判定 | 参照92本 |
|---|---|---|
| 研究文の最長連続 | 6文以上でWARN、9文以上でFAIL | 中央値3文 / p90が5文 / 最大8文 |
| 研究のある区間 | 6区間未満でWARN | 中央値9区間。**研究ゼロの区間は報告のみで判定しない** |
| 情景の三点配置 | 開幕・中盤1件以上・終盤でWARN | 中盤の情景は中央値3件 |
| 疑問文で終わる段落 | 4件未満でWARN | 疑問文は中央値12文 |
| 巨視化 | 1件未満でWARN | 中央値6件 |
| メタ発話 | 4〜6件でWARN、7件以上でFAIL | 中央値1件 / p90が3件 / 最大6件 |

### 分布(自前の規律)

| 項目 | 判定 | 参照92本との差 |
|---|---|---|
| 想定反論の往復 | 3件未満でWARN。うち1回はP28以降 | 中央値も3回で一致 |
| 承認句のある段落 | 3件以上でWARN | 参照のp90は3件。**こちらは1件きつくする** |
| 現代語への翻訳 | 3件未満でWARN、5件が目安 | **参照の中央値は1件。意図的に多く取る** |
| 限界と反証 | 0件でWARN | **参照の中央値は0件。完全に自前** |
| 二人称の呼びかけ | 8件未満でWARN | 中央値12回。p10は4回 |
| 敬語 | 最終2段落以外でWARN | 自前 |
| 煽り語 | 検出でWARN | 自前 |
| 禁止記号 / 中黒 / 英字 / パーセント記号 | **FAIL** | TTS仕様 |

**FAILが1つでも残っている状態で納品してはならない。**

## 第2段階:目視チェック(機械では測れない項目)

### 構造

- [ ] **冒頭への回帰を入れたなら、語の一致ではなく本当に同じ場面に戻っているか。** 機械は共通語の数しか見ていない。**入れない選択も可**(参照でも実行は51パーセント)
- [ ] **戻ったあとで、その場面が最初とは違って見えることを示せているか。** ただ繰り返しただけになっていないか
- [ ] **中盤の情景が3回入っているか。** 参照92本の中央値である。これを守れば研究の薄い区間は自然にできる
- [ ] **中盤の情景が、冒頭とは別の場面になっているか。** 冒頭の場面を中盤で使うと、着地の回帰が効かなくなる
- [ ] **手順から描いた主役研究が3本以上あるか。**「誰が、いつ、何人に、何をさせ、何を測ったか」
- [ ] **研究引用は8〜12本あるか。** 各引用が「年号+機関+人名+N数+結果数値」のフルセットか
- [ ] **飛び道具が、本当に「一見無関係な領域」から来ているか。** 同分野の研究をもう1本足しただけになっていないか
- [ ] **非対称が「Aは成り立つが、Bは成り立たない」の形で一行に圧縮できるか。** できないなら、この回の芯がまだ立っていない
- [ ] **巨視化に、年号つきの具体的な事件と情景があるか。** 抽象的な「昔は違った」で終わっていないか
- [ ] **開幕の予告が、結論を漏らしていないか。** 驚きの形だけを見せているか

### 視聴維持

- [ ] **想定反論が「本当に視聴者が思いつく反論」になっているか。** 藁人形を立てて倒していないか
- [ ] **現代語への翻訳が、視聴者がすでに知っている具体物になっているか。** 別の抽象語に言い換えただけになっていないか
- [ ] **各周回で最低1回、主張の切り返しがあるか**
- [ ] **視点が回転しているか。** 当事者側→反対側→供給側→巨視側と回り、どの時点でも「まだ語られていない側」が残っているか
- [ ] **設計図を音読していないか。** 機械が拾えない言い回しでも、「ここで〜してみたい」の類が残っていないか(`style.md` 冒頭の言い換え表)

### 文体とファクト

- [ ] **比喩が1周回に2つ以上出ていないか**(現代語への翻訳はこの制限の対象外)
- [ ] **丸めた数字を使っていないか。** 精密値が出せる箇所で「約〇割」に逃げていないか
- [ ] **実在しない研究・数値を書いていないか。** 記憶が不確かな箇所を精密値で偽装していないか
- [ ] **相関を因果と断定していないか**
- [ ] **実在の個人・団体を悪玉にしていないか。** 犯人を構造に置いているか
- [ ] **着地が視聴者を断罪していないか。** 救済・和解・返却・問いのどれかで、**武器か赦しか問いを手渡して**終わっているか
- [ ] **ファクトチェックリストを添付したか。** 確度「中」「要確認」の項目に、公開前検証が必要である旨を書いたか

## 直し方の優先順位

1. **「総文数」の超過** — 繋ぎ文と言い換えを削る。**研究は減らさない。** v5.0で最も出やすいWARNはこれである
2. **「メタ発話」の超過** — 転換の宣言を消し、転換した内容から書き出す
3. **「研究文の最長連続」が6文以上** — その段落を割り、あいだに意味づけの地の文を1〜2文入れる
4. **「想定反論の往復」の不足** — 視聴者の反論を代弁し、越える段落を足す。視聴維持に最も効く
5. **「現代語への翻訳」の不足** — 研究や概念の直後に、視聴者の日常の具体物へ対応させる
6. **「冒頭への回帰」のWARN** — P34〜P36を冒頭の情景に戻る2段落に書き直す。または入れないと決める
7. **総字数の不足** — 脇役研究を主役研究に昇格させ、手順から描き直す

**繋ぎ文や言い換えによる水増しは禁止。** 字数だけ増えて密度が落ちた台本は、字数不足の台本より悪い。

字数不足の主因は執筆時の手抜きではなく、**素材不足のまま書き始めること**である。増築しても埋まらないときは、工程1に戻って素材を探し直す。

## よくある不合格パターン

| 症状 | 真因 | 対処 |
|---|---|---|
| **総文数が250文を超える** | 地の文で同じことを二度言っている | 一段落あたりの文数を数える。5文を超える段落を疑う |
| **メタ発話が7件を超える** | 転換を毎回宣言している | 宣言を消し、転換した内容から書き出す |
| 総字数が5,000字前後で止まる | 工程1の素材が15行に届いていない | 工程1に戻る。テーマ変更も検討 |
| 冒頭への回帰が書けない | 冒頭の情景が抽象的すぎる | P1に固有の場面(時刻・場所・物)を置き直す。抽象的な逆説だけだと戻る先が無い。**入れないと決めてもよい** |
| 非対称性が薄い | 一行に圧縮できていない | 「Aは成り立つが、Bは成り立たない」を先に書く |
| 限界と反証が書けない | 主役研究の追試・批判を調べていない | 工程1に戻り、柱の研究それぞれの境界条件を1行ずつ調べる |
| 飛び道具が書けない | 用意していない | 暗号理論・動物行動・スポーツ・軍事・宗教・歴史から同型構造を探す |
| 想定反論がFAILになる | 反論を「潰す」つもりで書いている | 代弁してから越える。ただし承認句は2段落までに抑える |
| メタ発話がFAILになる | 転換を宣言している | 宣言を消し、転換した内容から書き出す(`style.md` 冒頭の言い換え表) |
| 台本が説教くさい | 悪玉を作っている。または視聴者を断罪している | 犯人を構造に置き、視聴者には武器か赦しか問いを手渡す |
