# 工程4:出力前の自己監査

**不合格があれば、削るのではなく増築してから再確認する。**

---

## 第1段階:機械チェック

```bash
python3 tools/audit.py output/<ディレクトリ>/03_台本.txt
```

自動判定される項目:

| 項目 | 基準 |
|---|---|
| 本文の総字数 | 6,500字以上 |
| 段落数 | 41(38未満はFAIL) |
| ビート別字数 | 各ビートが目標字数の80パーセント以上 |
| 重量級ビート10・17・24・30・37 | 各200字以上 |
| ブロック末尾13・20・27・32・36 | 疑問文で終わる |
| 裏切り予告(ビート13)の位置 | 全体の30〜55パーセント地点 |
| 禁止記号 | 【】→:※!?…—()等が本文に無い |
| 中黒の用法 | カタカナ名の区切り以外に使われていない |
| 英字の残存 | カタカナ化漏れが無い(定着略称は除外) |
| シグネチャ | 末尾が規定の締め文 |

**FAILが1つでも残っている状態で納品してはならない。**

`--verbose` を付けると全41ビートの字数一覧が出る。増築対象を探すときに使う。

---

## 第2段階:目視チェック(機械では測れない項目)

機械チェックが通ってから、以下を1項目ずつ確認する。

### 素材と構造

- [ ] **41ビートのうち、役割を果たしていないビートはないか。** 字数だけ埋まっていて中身が繋ぎ文になっているビートは無いか
- [ ] **手順から描いた主役研究が3本以上あるか。** 「誰が、いつ、何人に、何をさせ、何を測ったか」が書かれているか。結果の一行要約だけの研究は主役に数えない
- [ ] **研究引用は8〜12本あるか。** 各引用が「年号+機関+人名+N数+結果数値」のフルセットになっているか
- [ ] **ミクロ情景が4つ以上あるか**(ビート11・19・27・35)。場所+時刻+人物+動作+数字が揃っているか
- [ ] **冒頭ビート1〜2の数字が、ビート20か24で再登場し、構成が環になっているか**
- [ ] **ビート17の傍証が、本当に「一見無関係な領域」から来ているか。** 同じ分野の研究をもう1本足しただけになっていないか
- [ ] **ビート30に、年号つきの具体的な事件と情景があるか。** 抽象的な「昔は違った」で終わっていないか
- [ ] **ビート24が冒頭と呼応しているか**

### 視聴維持

- [ ] **裏切り予告(13)が、視聴者の予想を正確に代弁できているか。** 誰も思いつかない予想を代弁しても効かない
- [ ] **各ブロックで最低1回、主張の切り返しがあるか**(反転の往復)
- [ ] **視点が回転しているか。** 敗者側→勝者側→企業側→文明史側と回り、どの時点でも「まだ語られていない側」が残っているか
- [ ] **二人称の呼びかけが60〜90秒に1回あるか**

### 文体とファクト

- [ ] **煽り語(ヤバい、衝撃、絶対、驚愕)が無いか**
- [ ] **敬語がビート40〜41以外に出ていないか**(引用文中を除く)
- [ ] **比喩が1ブロックに2つ以上出ていないか**
- [ ] **丸めた数字を使っていないか。** 精密値が出せる箇所で「約〇割」に逃げていないか
- [ ] **実在しない研究・数値を書いていないか。** 記憶が不確かな箇所を精密値で偽装していないか
- [ ] **相関を因果と断定していないか**
- [ ] **実在の個人・団体を悪玉にしていないか。** ビート23で「〜が悪いという単純な話ではない」と明言しているか
- [ ] **ファクトチェックリストを添付したか。** 確度「中」「要確認」の項目に、公開前検証が必要である旨を書いたか

## 増築の優先順位

不合格が出たときは、この順で直す。

1. **脇役研究を主役研究に昇格させ、手順から描き直す** — 最も効率よく字数と密度が同時に増える
2. **歴史反転ビート(30)に事件の情景を足す** — 年号・場所・人物・動作
3. **帳簿ビート(24)に制度・訴訟・法改正を足す** — 年月つきで
4. **ミクロ情景を追加する** — 場所+時刻+人物+動作+数字

**繋ぎ文や言い換えによる水増しは禁止。** 字数だけ増えて密度が落ちた台本は、字数不足の台本より悪い。

字数不足の主因は執筆時の手抜きではなく、**素材不足のまま書き始めること**である。増築しても埋まらないときは、工程1に戻って素材を探し直す。

---

## よくある不合格パターン

| 症状 | 真因 | 対処 |
|---|---|---|
| 総字数が5,000字前後で止まる | 工程1の素材が15行に届いていない | 工程1に戻る。テーマ変更も検討 |
| ブロックDが薄い | 「誰がいくら儲けているか」を調べていない | 原価構造・業界売上・利益率を素材台帳に追加 |
| ビート17が書けない | 飛び道具の傍証を用意していない | スポーツ・動物・軍事・宗教・歴史から同型構造を探す |
| ビート30が抽象論になる | 歴史反転の史実が無い | 「反転させた発明・事件」を年号つきで特定する。無ければ文明史的な位置づけに切り替える |
| 台本が説教くさい | 悪玉を作っている | ビート23を書き直し、売る側も同じ構造の中にいることを示す |
